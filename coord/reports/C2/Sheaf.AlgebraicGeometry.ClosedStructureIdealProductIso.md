## What changed
Repaired the landing failure returned by reviewer X-233d1. The main declaration
`AlgebraicGeometry.Scheme.Modules.closed_structure_ideal_product_iso` retains its exact
signature, visibility, docstring and public imports. All changes are in its proof and
proved private helpers; no other existing module is adapted.

The five duplicate declarations are eliminated, rather than merely renamed:
- `ideal_qc` is removed. The main proof obtains the required instances directly from
  the existing quasi-coherent kernel and qcqs pushforward theorems.
- `image_range_affine` is replaced by `image_range_eq_abelian`, which compares the two
  categorical images on every open, without affineness or quasi-coherence assumptions.
  The existing public affine image formula supplies the further equality with the
  original morphism's range.
- `product_range_affine` is generalized to `tensor_image_range_affine`: any morphism
  from a tensor product of quasi-coherent modules to any quasi-coherent target has an
  affine image generated by the images of pure tensor sections. Ideal multiplication
  is a specialization in the main proof, using the existing unitor section formula.
- `hom_zero_of_affine` is generalized to `hom_eq_iff_affine`, an equivalence for equality
  of two arbitrary morphisms, with both directions proved.
- `subobject_le_of_affine_range` is generalized to `subobject_le_iff_affine_range`, an
  equivalence with both directions proved. The added forward implication explicitly
  constructs the factorization from `Subobject.ofMkLEMk`.

The modules containing the original helpers cannot be imported: their helpers are
private and both modules already reach this item, so those imports would make cycles.
The generalizations keep the existing proofs' mathematical content and strictly enlarge
what the local helpers establish. The lexical scope changes and repair are recorded in
`coord/changes/closed-structure-proof-scopes.md`. Updated the node's proof text to match.
