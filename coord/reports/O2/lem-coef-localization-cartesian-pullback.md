## Source error

Proposition 5.3.16 cites HTT Corollary 2.4.4.5 for preservation of the pushout by Cartesian base change. That corollary states preservation of categorical equivalences between infinity-categories. The supporting pushout node instead cites HTT Proposition 3.3.1.3 (the corresponding equivalence assertion for arbitrary simplicial sets) and Corollary 3.3.1.4 (strict Cartesian base changes compute Joyal homotopy pullbacks), together with the homotopy-colimit comparison of Section 4.2.4.

Here is the consequence behind that citation: compute a pushout using a cofibrant span over D, whose legs are monomorphisms. Degreewise base change preserves these monomorphisms and ordinary colimits. Proposition 3.3.1.3, applied also after base change to each intermediate simplicial set over D, preserves its replacement equivalences. Corollary 3.3.1.4 identifies all resulting strict pullbacks with the required infinity-categorical pullbacks. The pulled-back cofibrant span therefore computes the required pushout. This repairs an incomplete source citation, without changing the item's statement or proof route. The new node is left statement-only as required.
