## Supporting argument for the new unsplit node

For `lem-sfb-affine-smooth-trivialization-lift` I read More on Morphisms 06AD (`lemma-thickening-affine-scheme`) and 02H0 (`definition-formally-smooth`), and Algebra 00TN (`proposition-smooth-formally-smooth`). These give a direct proof of the relative marked form needed here; the assertion is not quoted as the verbatim statement of any single Stacks lemma.

Write T = Spec P. Its R/I-base change is affine. Since I is nilpotent, D over R/I is a finite-order thickening into D, so 06AD shows D = Spec C is affine. The given theta_0 gives a k-algebra map P to C/IC, and P is formally smooth over k. Lift this map to P to C by iterating the first-order lifting condition along powers of IC; each successive kernel is square zero. Extending scalars gives f: R tensor_k P to C with the prescribed reduction. The target C is R-flat, by the affine flatness criterion. Reduction of f modulo I is an isomorphism.

Here is the flat comparison, without any finiteness assumption on C. The cokernel M of f satisfies M/IM = 0, so M = IM = I^N M = 0; hence f is surjective. Put H = ker f. Tensoring 0 to H to R tensor_k P to C to 0 with R/I preserves injectivity on the left because C is R-flat. The reduced map is an isomorphism, hence H/IH = 0. Again H = IH = I^N H = 0. Thus f is an isomorphism, whose spectrum is the required theta with exactly the original theta_0 as reduction. This argument is recorded here only: the new node itself has no proof steps and is left unsplit for the next level.

This is a genuine supporting lemma: it concerns one affine smooth model over a general nilpotent quotient and a specified marking. It mentions no covering, second open, given deformation Z, or gluing. The item's construction, structural morphism, flatness, reduction isomorphism and compatibility equation remain proved in its own steps. It is longer than an elementary two-line fact: it requires affineness of thickenings, a formal-smooth lift and the flat nilpotent comparison.
