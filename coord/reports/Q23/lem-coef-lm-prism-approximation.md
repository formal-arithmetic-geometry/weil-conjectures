## Arguments for the new nodes

For the algebra lemma, ordered substitution in T_alpha h = D_delta gives, for each output i, concatenation C_{alpha(i-1)+1} ... C_{alpha(i)} equal to the increasing interval (delta(i-1),delta(i)]. Concatenate these equations over all i. Since alpha starts at 0 and ends at s, the entire list C_1 ... C_s is exactly (delta(0),delta(n)]. Each sublist C_j therefore consists of consecutive entries in that increasing list. Cutting at their cardinalities gives C_j=(lambda(j-1),lambda(j)], where lambda(j)=delta(0)+sum_{l<=j}|C_l|. Thus lambda is monotone and bounded by delta(n)<=r, and counting up to alpha(i) gives lambda(alpha(i))=delta(i). Since T_alpha is active, it discards no input; consequently precisely the inputs already absent from D_delta are discarded by h. This includes the module input for a cross source. These fibre and discard descriptions are exactly D_lambda. When s=0, the equality forces all D_delta algebra fibres empty, hence delta constant, and the same formula applies.

For the module lemma, the algebra-output equations give the intervals as above only up to alpha(n). The final output equation gives the additional concatenation C_{alpha(n)+1} ... C_s C_{s+1}=(delta(n),r+1]. Concatenating all output equations therefore gives C_1 ... C_s C_{s+1}=(delta(0),r+1]. The last sublist contains the unique module input last, by the LM morphism rule, hence is nonempty. Splitting this full interval at the cardinalities of the algebra sublists gives their asserted intervals, lambda(s)<=r, and C_{s+1}=(lambda(s),r+1]. The algebra-output equations yield lambda(alpha(i))=delta(i). B_alpha is active because alpha(0)=0, so the discarded set of h is that of B_delta, namely the initial segment. These data determine h=B_lambda. The same argument works for n=0 or s=0, with empty algebra concatenations and a nonempty module tail.

Neither argument assumes positive arities, nonempty algebra fibres, faithfulness of Cut, or a global cocartesian condition. They are non-elementary ordered-list reconstruction claims, not renamed clauses of the item.
