## Source error in a cited node's latest blueprint proof

The latest blueprint proof for `pqf-lem-affine-open-locnoeth` claims that a localization R_h is generated by 1/h as an R-module. This is false: Z[1/2] is not finitely generated as a Z-module, since finitely many fractions have bounded powers of 2 in their denominators. Its later uniform exponent for an arbitrary ideal before proving finite generation is also not justified. The cited node's statement is true and is exactly Stacks Tag 01OW (2), whose proof uses the locality of the Noetherian ring property. My item uses only that statement and follows the Stacks argument; it does not rely on the erroneous latest blueprint proof. The other node is read-only and has not been edited. This report brings the source-proof defect to the maintainer's review.
