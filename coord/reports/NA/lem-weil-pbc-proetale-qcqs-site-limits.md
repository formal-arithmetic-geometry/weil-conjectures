## Statement corrected
STATEMENT-DISPUTED: the imported item asserted finite limits in the qcqs subcategory for every base scheme. Take $X=\coprod_{n\ge0}\operatorname{Spec}k$. Any terminal qcqs object $Q\to X$ would receive a unique $X$-map from each component $\operatorname{Spec}k$, so its image meets every component. The inverse images of the components would be infinitely many nonempty disjoint opens covering the quasi-compact scheme $Q$, an impossibility. Thus even a terminal object need not exist. The first worker's expanded fibre-product node incorrectly also asserted that this subcategory contains $X$.

Correction: retain arbitrary $X$ for the site and fibre-product assertions; state finite limits in every slice over a qcqs object, and in the whole subcategory when $X$ is qcqs. This follows the actual 09A1 qcqs paragraph, which asserts fibre products, not unrestricted finite limits. This is a supporting node, not a change to any Challenge target. The parent lem-weil-pbc-proetale-qcqs-finite-family-geometry also repeats the false unrestricted finite-limit assertion; the maintainer must propagate this correction there (outside this delivery's scope).
