## Statement corrected

STATEMENT-DISPUTED: the imported statement introduces a closed immersion i:Z into projective space over T and a flat finitely presented f:Z to T, but never identifies f with the structural composite. Taken literally it is false. Let k be any field, T = A^1_k disjoint union Spec k, n = 0, and Z = A^1_k, embedded as the first closed-and-open component of P^0_T = T. Let f instead map Z to the point component by its structure morphism. This f is flat and finitely presented: on the point component it is A^1_k to Spec k, and on the other component its inverse image is empty. It is not proper, since its base change to the point component is A^1_k to Spec k. For instance the map from the generic point of Spec k[[u]] with coordinate u^{-1} has no extension to Spec k[[u]].

The correction explicitly introduces the structural projection pi and sets f = pi composed with i. This is precisely what the source calls the morphism of the projective family; it changes no conclusion and removes no intended case. Without this relation even the relative flatness argument and interpretation of the base-change embedding are about the wrong morphism.
