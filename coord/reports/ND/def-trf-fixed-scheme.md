## Maintainer review fix (2026-10-18)

The independent maintainer review found one clause rendered too weakly. The node says that for every scheme `T`, a morphism `T → Fix(h)` is uniquely specified by a morphism `t : T → X` with `h ∘ t = t`. That is a bijection from `Hom(T, Fix(h))` onto the fixed `t`. The delivered `trfEndomorphismFixedScheme_equalizer` stated only `(∃! g, g ≫ incl = t) ↔ t ≫ h = t`. This does not say that every composite `g ≫ incl` is fixed, so on its own it gives neither the map onto the fixed set nor injectivity on composites that are not fixed. The fix adds the conjunct `∀ g : T ⟶ Fix(h), (g ≫ incl) ≫ h.left = g ≫ incl`. With it, the theorem says exactly that composition with the inclusion is the stated bijection. The proof docstring was extended to match. No declaration name, record field or other statement changed. The fixed file compiles through `tools/nt_compile.py` with return code 0 and no diagnostics.
