## Source error

STATEMENT-DISPUTED: the imported defining paragraph says that `X' -> T` is a resulting projection. There is generally no such morphism. Take `S=S'=Spec Z`, `a=id`, `X=X'=Spec Q`, and `T=Spec F_2`. The morphism `g:T -> S'` is a quasi-compact quasi-separated closed immersion, and `Y=X' ×_{S'} T` is empty. A morphism `X' -> T` would require a unital ring homomorphism `F_2 -> Q`, which is impossible. The two projections actually have source `Y` and targets `X'` and `T`.

I corrected this to `h:Y -> X'` and `e:Y -> T`, as the imported diagram already suggests and Stacks explicitly states. The source is Stacks Tag **0F02**, `etale-cohomology.tex`, label **remark-base-change-holds**, lines 16848–16867 in the local mirror. It gives exactly the map `(f')^{-1} R^q g_* F -> R^q h_* e^{-1} F` for every base change and every qcqs `g`, every n-annihilated abelian sheaf on `T`, and every `q <= q_0`. The blueprint file `master/blueprint/sec-smooth-purity/sk-prop-sf-kunneth-ordinary/def-kun-bc-property.md` contains the same typo. The correction follows the cited source's intent and changes no quantifier or coefficient restriction.

The old cohomological-dimension sentence is unrelated to the definition and is removed, together with `def-kun-cd` from its dependencies: no dimension bound occurs in Tag 0F02 or in this predicate. Reading that node also shows it defines torsion cohomological dimension, not a new prerequisite for this base-change condition.

The imported reference to `lem-kun-bc-map-on-cohomology` has been removed as a defining ingredient: that node explicitly has abelian-group coefficients, whereas this definition specifies the unbounded module exchange at `Z/nZ`. I have not claimed that its statement supplies a module/abelian comparison theorem. The definition now directly takes cohomology of the existing module exchange. Its orientation is explicit, and the same map is already defined for general commutative coefficients in `sbc-def-base-change-map`. This avoids asserting a separate comparison between two coefficient categories or silently rotating the wrong pair of maps.
