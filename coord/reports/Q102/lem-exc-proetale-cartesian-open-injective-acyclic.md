## Extracted argument retained for the new node

For a weakly etale site object g:Y→X and an object Z→Y, composition makes Z→X an object of X_proet. In the category I_Z from `def-weil-proetale-inverse-image`, an object (H, Z→Y×_X H) is equivalently an X-morphism Z→H. The object (Z→X, (Z→Y,id_Z)) is initial in I_Z and hence terminal in I_Z^op, the actual colimit index in that definition. Thus the presheaf inverse image evaluates to F(Z→X), naturally in Z and F. By `lem-weil-proetale-weakly-etale-localization` this restriction is already a sheaf. The same calculation applies to ring sheaves and to the module action maps. Under it the adjoint constant-ring map sends every constant scalar to itself; uniqueness in sheafification identifies it with the canonical restricted-ring identification of the localization lemma. Tensor extension along this ring isomorphism identifies module pullback with restriction: m⊗a maps to a·m, with inverse m↦m⊗1. This proof sketch is in the report only; the new unsplit node has no proof or proof dependencies.

The initial/terminal distinction matters: the colimit is over I_Z^op, not I_Z. This also works over an empty scheme, for the zero ring, and for non-monic weakly etale g (for example the projection X⊔X→X). Hence the new statement does not silently require that g be open or quasi-compact.
