For the new node I checked the intended algebraic argument as follows. Alternating deletions square to zero. On each basis symbol, the insertion maps satisfy d c_i+c_i d=1-R_i: if color i is missing, deleting the inserted vertex gives the identity and other faces cancel; if it is present, only deleting that vertex permits a subsequent insertion, giving the replacement term with positive sign. Each R_i commutes with d, either by that identity and d squared zero or by the same faces calculation. Hence the displayed finite sum S satisfies dS+Sd=1-R_0...R_{r-1}, by telescoping. For a symbol of degree less than r-1, a missing color makes this product zero: all other R_j preserve the color set or kill the term. Maps preserving anchors commute with insertion and replacement. Expansion uses only fixed insertions/replacements, so the finite-formula naturality assertion is part of the actual statement, not an unrecorded feature of a future proof. This is the substantial algebraic sublemma left unsplit; the chain comparison and cocycle argument remain in the item.
