## Source error

For example, the etale chart Spec C -> Spec R has a closed chart point with residue C, whereas the target point has residue R. The proof here consistently uses L = kappa(w_0). Local finite type plus closedness makes L/kappa(u_0) finite, which is exactly enough for Tag 07XG. This is a correction of the source's proof notation, not a dispute or change to the item's statement.
