The criterion is explicitly an agent-formulated consequence, not a claim that 02HM literally mentions differential bases. Here is the argument motivating this smaller input. A smooth R-algebra A lifts an R-map to E/J across any square-zero ideal J. For a specified map from R[X_i], choose such an R-lift f and let e_i be its errors on t_i relative to the specified X_i-images. Each e_i lies in J. The prescribed differential basis defines a unique R-derivation d:A -> J with d(t_i)=e_i, with J an A-module through the residue lift. Then f-d is a ring map because J squared is zero and it fixes all the prescribed t_i. Two lifts differ by a derivation vanishing on every t_i, hence by zero. Finally, if A=R[z]/(q) is finitely presented and t_i is represented by p_i(z), it has the finite presentation R[X,z]/(q,X_i-p_i(z)) over R[X]. Apply 02HM. This is a general square-zero correction lemma for a prescribed map, not a restatement of the implicit-coordinate conclusion. The new node itself contains only the self-contained statement, no proof steps or proof dependencies.
