## What was wrong and what changed

The return was correct. Strict local refinements are not unique or functorial for restriction: further blowups of a node or a smooth special point give other strict models with the same generic identification. Therefore the previous overlap assertion provided neither gluing data nor a cocycle. Its marking argument also failed: distinct generic sections can have intersecting closures and the unmarked strict cofinality statement gives no marking control. Common-cover assumes reducedness and finitely many components; it does not prove them.

The repaired proof constructs the reduced common product first, citing horizontal-curve-models. It makes **stable** local refinements, using the actual output of marking-semistable-separation before contraction. It constructs and proves the overlap comparisons through the smaller component-inclusion and component-factorization statements. It checks properness of the glued curve map on the target cover. It finally strictifies the single global semistable pair, through a new sourced statement with the marking included.

A direct invocation of the existing stable-reduction theorem is circular: stable-reduction → general stable-uniqueness → semistable-dominates-stable → this item. Replacing that theorem by a differently named copy would not repair it. This repair does neither. The local overlap comparison is expanded using a dense compactification and the existing strict-target cofinality theorem, exactly the special-case method of Corollary 4.4.3(ii). No existing node's proof or dependencies were edited.
