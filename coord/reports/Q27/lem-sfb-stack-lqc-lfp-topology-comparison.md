## Review by Q27

I checked the item against 076T and all three parts of 075R in stacks-sheaves.tex. The item asks exactly for parts (1) and (3) and includes the sheaf assertion. In particular, I kept locally finite presentation in every use of the comparison hypothesis. I did not use the stronger existing lem-sfb-stack-lqc-flat-comparison-local-structure, whose flat-compatible category assumes all flat arrows.

For the new localization node I read 06W0 and 06W9 and the definition-pullback paragraph. The statement uses a category fibred in groupoids, not an arbitrary category over schemes: this is what makes the slice functor an equivalence. It keeps both the inherited topology and the value of the structure sheaf on each scheme. A nontrivial automorphism group in a fibre causes no counterexample: specifying the arrow into x in the slice removes those automorphisms. For a representable fibred category the equivalence reduces to the usual iterated slice; for an empty fibred category there is no object x to which it applies.

For the new affine node I read 0756 with tau = etale, g = id_U. It compares big-fppf cohomology with small-etale cohomology at U. Affine quasi-coherent acyclicity gives zero in positive degree. Its statement does not assert that G equals the cartesian extension on arbitrary objects; the source's proof specifically handles the resulting parasitic kernel and cokernel. The affine hypothesis is essential: on a projective curve a quasi-coherent module can have positive cohomology. The zero module and U = Spec(0), including the empty cover, give zero. Nothing uses Noetherianity, finite generation or comparison over a nonflat map. The new statement deliberately takes just this scheme-affine input and leaves the topology comparison itself in the item's steps.

For the fibre-cohomology node I read the statement and injective-resolution proof of 075G. It assumes algebraic stacks, as that lemma does; no assertion for arbitrary fibred categories is imported from the footnote. The fibre is the 2-product over the test object y, and the coefficient is precomposition p_y^{-1}M. The source proves that the representable projection preserves injectives, so the section complex computes precisely the displayed fibre cohomology. The statement keeps the sheafification and the scalar actions rather than claiming equality of raw sections with R^qh_*M. At q = 0 it recovers the section formula. For h = id it reduces to sheafification of object cohomology, not vanishing of every raw positive cohomology group. An empty source gives zero.

The comparison epsilon is the morphism presented by the identity continuous functor, so this node applies.
