## Source error

STATEMENT-DISPUTED: the imported conclusion over an arbitrary field is false. The correction is that there EXISTS a finite extension K/F for which E(M_K) is clopen. It is not legitimate to make a finite extension perfect; the proof first works over an algebraic closure and then descends the particular trivialization. This restores the quantifier in Guo's Claim 5.2.1 and its preceding perfect-closure reduction. The original imported helper had omitted that reduction.

Here is an explicit counterexample to the imported statement. Put p=3 and F=F_p(a), with a transcendental. Let

G = Spec F[w,t]/(w-w^p-a t^p),
H = Spec F[x,y]/(x+x^(p^2)+a y^(p^2)),

with their origin points. Both are smooth geometrically integral affine curves: the partial derivatives in w and x are 1; after a purely inseparable extension they are affine lines. For H, if b^(p^2)=a then z=x+b y gives x=-z^(p^2), y=(z+z^(p^2))/b. There is a nonconstant alternating morphism h:H x H -> G given by

w=x1*x2^p-x1^p*x2,  t=x1*y2^p-y1^p*x2.

Indeed w-w^p = x2^p(x1+x1^(p^2))-x1^p(x2+x2^(p^2)) = a t^p. Both axes map to the origin. Nonconstancy can also be checked after substituting the displayed affine-line parameter on each H.

The regular projective completion C of G is the plane curve W Z^(p-1)-W^p=a T^p. Its unique boundary point P has residue degree p. In the chart T=1 its ideal is generated by Z and the quotient F[W]/(W^p+a) is a field; thus its one-dimensional local ring has principal maximal ideal and is regular. The affine part is smooth. The curve is geometrically integral and has arithmetic genus (p-1)(p-2)/2=1.

On (H x H) x C form O(graph(h)-graph(0)), whose graphs lie in the smooth locus and are Cartier divisors. Tensor by the inverse pullback of its restriction to (H x H) x {0}; call the normalized line P_h. This normalization makes that restriction trivial, and the two H axes remain trivial because h is zero on them. Restrict P_h to (H x H) x G, and call it M. Then the original item's U=V=H, T=G and u=v=0 hypotheses hold, and M_0 is trivial.

M is not globally trivial. At the generic point s of H x H the class of P_h on C_s is O(h(s)-0), a nonzero degree-zero class. The completion stays regular under this separably generated extension. If that class were zero, a function with divisor h(s)-0 would give a degree-one map C_s -> P^1, contradicting genus one. Removing the single boundary point cannot kill this class: the kernel of Pic(C_s)->Pic(G_s) is generated by P_s, whose degree is p, whereas our class is nonzero of degree zero. Thus M is nontrivial on the generic H x H slice and hence globally. If its generic G-fibre were trivial, Tag 0BD7 applied to (H x H) x G -> G would give M=f^*N; the section (0,0) makes N trivial. This contradiction shows that E(M) contains 0 but not the generic point of the integral scheme G. It is therefore not clopen.

The correction affects the existing parent lem-sfb-field-square-after-finite-extension: at its step 4 one must enlarge its already chosen finite K once more before using this helper. All subsequent steps then run over this enlarged finite field; its conclusion already allows that. I did not edit the parent, which is outside my ownership. The maintainer must update that application when accepting this statement correction. No Challenge target is changed here.
