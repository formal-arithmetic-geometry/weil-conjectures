Why the homomorphism binder has exactly the node's meaning: write B = completed S,
C = completed R, and i : C → B for the canonical completed structural map. Restricting
a C-algebra map gives the displayed R-algebra map. Conversely, any R-algebra map
σ : B → C carries (JB)^n into (JC)^n for each n, because the extended ideals and their
powers are generated by images of the same elements of J^n. Thus σ is adically
continuous. The canonical map i is continuous by the same calculation. On the dense
image of R, σ composed with i agrees with the identity, by `AlgHom.commutes`.
C is Hausdorff and R is dense in C, so σ composed with i is the identity everywhere.
The same continuity-and-density argument shows σ(i(c)b) = cσ(b), for all c and b.
Thus σ is exactly a C-algebra map, automatically surjective and a retraction of i.

or an extra assumption. No choice of a completed algebra structure is introduced.
