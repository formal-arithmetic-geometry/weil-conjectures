## Worker report

The module `Sheaf.AlgebraicGeometry.AlgebraicSpace` defines algebraic spaces over a
scheme, their morphisms, representable/étale/surjective maps, the small étale site,
the regular-functions structure sheaf, its module category, restriction along étale
maps, and line modules. No statement correction or dependency repair is needed.
No definition chooses an atlas or any other unspecified data.

Clause-by-clause correspondence:

| Node clause | Lean rendering |
| --- | --- |
| Scheme S and size convention | Explicit `universe u`, `S : Scheme.{u}`; all test schemes are `Over S` in the same scheme universe, and presheaf values are `Type u`. The category of tests is in `Type (u+1)` with scheme morphisms in `Type u`; no equality of object and morphism universe levels is assumed. This is a fixed universe-bounded presentation of the site. |
| F is a sheaf of sets on the big fppf site over S | `F : Sheaf (Scheme.fppfTopology.over S) (Type u)` in `IsAlgebraicSpace`. `Scheme.fppfTopology` is generated by the jointly surjective flat, locally finitely presented families; `.over S` is its big slice site. |
| h_U(T) = Mor_S(T,U) | Mathlib `yoneda.obj U` on `Over S`, with no replacement representable functor. |
| A map G → F is representable | `IsRepresentableWith ⊤ f`: for every `T` and every `a : yoneda.obj T ⟶ F`, an actual `U : Over S`, projection `p : U ⟶ T`, map `q : yoneda.obj U ⟶ G`, and `IsPullback q (yoneda.map p) f a`. This is the universal-property formulation of a scheme representing the sheaf fibre product. Limits of sheaves are computed as presheaf limits. |
| Its scheme projections are étale, respectively surjective | `IsEtale` and `IsSurjective` use the same representing squares with `Etale p.left` and `Surjective p.left`. Asking for one representing square with the property is equivalent to asking it of every representation, since representing schemes are uniquely isomorphic over T and these properties are invariant under that isomorphism. |
| Representable diagonal F → F × F | `IsRepresentable (prod.lift (𝟙 F.obj) (𝟙 F.obj))`. The product and diagonal are those of the presheaf category. |
| Representable, surjective étale atlas from a scheme U over S | `∃ (U : Over S) (a : yoneda.obj U ⟶ F.obj), IsEtale a ∧ IsSurjective a`. Each conjunct includes representability, not merely the property of an arbitrary selected map. The two witnesses represent the same pullback and are isomorphic over the test scheme, so the conjunction says exactly that the atlas is surjective and étale. |
| Morphisms are natural transformations | `AlgebraicSpace S` is the full subcategory of the sheaf category on the preceding predicate; its homs are the existing sheaf natural transformations. |
| Objects and arrows of the small étale site | `EtaleSite F` is the full subcategory of `CostructuredArrow yoneda F.obj.obj` on `IsEtale T.hom`: a scheme T/S, an étale map h_T → F, and commuting triangles as arrows. |
| Jointly surjective étale coverings | `etalePrecoverage` requires `Etale ((etaleForget F).map f)` on every arrow in the covering presieve and, for each point x of its target, a covering arrow and a source point y mapping to x. `etaleTopology` is the generated Grothendieck topology. |
| O_F(T) = Γ(T,O_T) | `structurePresheaf` is `(etaleForget F).op ⋙ Scheme.Γ ⋙ forget₂ CommRingCat RingCat`; `structureSheaf` packages exactly this presheaf with its named sheaf-condition theorem. Neither the rings nor their restriction maps depend on a postponed existence theorem. |
| A sheaf of O_F-modules | `Modules F` uses the dependency's `ringedSiteModules F.structureSheaf`, hence Mathlib's existing `SheafOfModules`, sectionwise linear morphisms and semilinear restrictions. |
| Locally isomorphic to O_F, called a line/invertible module here | `IsLineModule F M` quantifies over every object T, a covering sieve R of T, and every arrow U → T of R. It asks for `Nonempty ((F.etalePullback U).obj M ≅ SheafOfModules.unit (F.structureSheaf.over U))`. The isomorphism is on the localized site, not merely on global sections. This is rank one, not unspecified finite local freeness. |
| Pullback along an étale map is restriction | `etaleMap f hf` composes maps h_T → G with f : G → F and keeps the underlying schemes and arrows unchanged. `pullback f hf` is Mathlib module-sheaf precomposition along this continuous functor, with the identity map on each ring of regular functions. `etalePullback F T` is `SheafOfModules.overFunctor`, and `etalePullbackMap F f` is `SheafOfModules.overMap`, giving exactly restriction on localized sites. |

Edge cases checked mathematically before writing: the empty base and empty scheme
are allowed; no inhabitance or nontrivial-ring hypothesis occurs. An empty covering
is jointly surjective precisely when its target scheme is empty. Representable
sheaves h_U satisfy the algebraic-space definition using the identity atlas, with
no quasi-separatedness or quasi-compactness assumption. Identity maps satisfy the
scheme-test étale definition, and their restriction functors retain the same
underlying schemes. Zero modules on the empty space cause no exception to local
rank one. On a nonempty ordinary scheme, O^2 is not accidentally accepted as a line
module: the predicate requires a localized isomorphism to O, not arbitrary finite
local freeness. Every test-scheme quantifier uses the same universe as S, so it
includes S and cannot become vacuous through a smaller independent universe.
