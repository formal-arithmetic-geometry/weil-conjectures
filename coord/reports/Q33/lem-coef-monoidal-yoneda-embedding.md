## Arguments retained for the extracted nodes

For planar lifting, a finite tree uses each external variable once. Induction up the tree shows the composite M_T is separately cocontinuous: varying a leaf changes only one input at each vertex on its path to the root. The chosen vertex comparisons identify its restriction with f m_T. Restriction is an equivalence on the full categories of these operations, so it identifies transformation spaces and all their compatibility data. Lift the whole coherent tree diagrams, including grafting/substitution compatibility, not arbitrary transformations after extra inputs have been adjoined. The relevant homotopy fibers of the equivalences are contractible; restriction on zero inputs is the identity B. This gives existence and uniqueness of the simultaneous coherent lift. The existing block-normal-form node is used only after this lift.

For Kan recognition, use the existing cartesian-closedness theorem lem-coef-space-presheaf-cocompletion: X×− is left adjoint to Map(X,−). Its mapping-space adjunction on diagrams is the parametric-universal-arrows formula. Applied to a small colimit cocone and using the mapping-space colimit criterion in yoneda-presheaf-limits, this shows X×− preserves colimits, including the empty colimit. Hence external product of space presheaves preserves colimits separately by objectwise colimits; so does t*E. Finite-variable completion extends the prescribed map on representables to the transformation η, uniquely up to contractible choice. The evaluation theorem gives its mapping comparison on representables. Present each F_i by the small coherent density diagram supplied by space-yoneda-density. Separate preservation expresses both sides, after mapping into H or t*H, as the same r successive limits of H(t(a_1,…,a_r)). The comparison is composition with the already defined η, so these presentations test a canonical map instead of being choices that define it. At r=0 both mapping spaces are H(t(*)); there is no assertion that a constant functor preserves empty colimits. This is the old step 3 argument with the product-colimit subargument correctly supported by an existing cartesian-closedness node.

For the strict-base inverse, project the counit FG≃id to N(B). Each component is an isomorphism in B, hence an identity. The projected functors have equal vertices. On an edge, the two triangles of the natural transformation give an ordinary commutative square with identity vertical arrows, so its horizontal arrows agree. A simplex of an ordinary nerve is determined by its consecutive edges, which also determines the projected transformation to be the degenerate identity in all degrees. Therefore pG=q strictly, and the same argument makes the unit vertical. Postcomposition carries these actual simplicial inverse data to each strict fiber of a functor category. The gaunt hypothesis is essential to this particular strictness argument; arbitrary groupoid bases are not asserted.

For full restriction, inner-horn fillers in E with all horn vertices in R still have all vertices in R, so R→S is inner. The assumed cocartesian lifts remain in R and their mapping-space pullback property restricts to test objects in R. Conversely compare a cocartesian edge of R with an ambient cocartesian lift from the same source over the same base edge, whose endpoint is in R by the assumption. The cocartesian property inside R identifies their targets by an equivalence, so the original edge is also ambient cocartesian. Exponentiation of the two resulting cocartesian fibrations gives quasicategories over each fixed diagram. A simplex K×Δ^n→E factors through R exactly when every object value of every vertex diagram lies in R. Thus the relative inclusion is full and its right-pinched mapping simplicial sets are equal degreewise. This last clause concerns arbitrary transformations, not only cocartesian ones. These coupled fibration/reflection/relative-diagram assertions are the hidden structural lemma from old step 5, rather than an isolated two-line product identity made into a node.
