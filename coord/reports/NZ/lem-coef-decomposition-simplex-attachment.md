Edge cases checked mathematically before finalizing the statement:

- `m = 0`: `hfaces` is vacuous, the boundary is empty, every vertex is
  nondegenerate; the first square still attaches its pure lower vertex.
- Empty `I` or empty `I_σ`: the theorem has no `Nonempty` assumption and
  quantifies over no lift object. The join is then just `Δ[m]`; the pure lower
  restriction remains and the mixed/upper equations are vacuous as appropriate.
- Degenerate `σ`: its nondegenerate root is a proper face, so the pure lower
  simplex is already old. This remains true when `D_σ` is empty, because the
  second summand of the pushout contains the pure lower factor.
- Empty base `K`: there is no `σ`, so the universally quantified assertion
  imposes no unwanted nonemptiness claim.
- A constant noninjective structure map `Δ[1] → Δ[0]`: nondegenerate mixed
  simplices can have degenerate lower block. The definition tests
  nondegeneracy in `K_F`, keeping those simplices as required.
- Families containing a degenerate simplex but no higher degeneracies: the
  definition does not turn the lower family itself into a subcomplex; only
  the stated generated subset in `K_F` is closed under operators.
