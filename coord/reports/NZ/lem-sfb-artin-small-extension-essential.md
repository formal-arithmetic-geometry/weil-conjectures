Step 1 cites `def-sfb-artin-deformation-test-category` for the kernel and residue-field conventions, which its statement explicitly supplies. I checked that C is only an image subring; the proof never assumes an arbitrary subring of an Artinian ring is Artinian. Surjectivity of pg gives B = C + I element by element. Surjectivity C -> k follows from the specified identity on k, including for a complete source D. These are elementary consequences of the maps in the statement.

Step 2 uses the same definition's exact one-dimensionality and annihilation assertion. A nonzero x in C intersect I spans I over k. For every scalar lambda, choose a representative in C, whose residue map is surjective by step 1. Multiplication of this representative with x is lambda x: any two representatives differ in the maximal ideal, which annihilates I. Thus I is contained in C and B = C, contradicting nonsurjectivity. This proves C intersect I = 0 without citing a hidden module-length theorem. The calculation is elementary; I did not create a node restating the item's dichotomy.

The unique preimages define a section and uniqueness verifies both ring operations, the unit, and the R-structure. It gives both essentiality and the complete-source conclusion by the same contradiction; no unrecorded Artinian quotient or nilpotence lemma is used.
