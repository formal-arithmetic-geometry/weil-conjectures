## STATEMENT-DISPUTED

The imported constants have an actual empty-case defect: for `f: empty -> Spec k`, choose the empty cover of `f^{-1}(Spec k)`. Then both maxima run over an empty index family and no integers `D,c` are defined. I set `D=c=0` for an empty chart family. All sheaves on the empty scheme's site vanish by the empty-cover sheaf axiom, so this extends the same intended conclusion and adds no nonempty-case hypothesis.

The imported statement also concealed the finite-type-over-`k` setting behind “purity conventions”, although the conventions node only fixes coefficients and notation. I made `X,Y` finite-type `k`-schemes explicit, exactly as the unit statement and proof require. This is essential for the Noetherian/compactification inputs: `A=A_{E,n}` by itself does not make an arbitrary scheme finite type over `k`. The chart embeddings and covers are now explicitly chosen data, as they already were in the source, and both displayed intervals and both preservation clauses are unchanged on a nonempty family of charts.

The old proof's base-open formula `Rf_V^times ~= Lg_V^* Rf^times` was ill-typed: `g_V^*` takes objects on `Y` to objects on `V`, while `Rf^times` returns objects on `X`. The repaired formula is `Lh^* Rf^! ~= Rf_V^! Lg^*`, with `h:X_V -> X` and `g:V -> Y`. The same mistake occurred in the accompanying expression applying `g_V^*` to the output. Both are corrected in Step 2.

The old proof applied etale closed-immersion lemmas directly to pro-etale objects. Steps 5–6 now perform and justify that change of sites. It also concluded only vanishing when it needed constructibility as well; Step 8 supplies a finite locally closed disjointification of all chart stratifications.
