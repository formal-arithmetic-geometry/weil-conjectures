## Source error

Gepner–Haugseng Corollary 5.5.6, as displayed online, says that E_f is a categorical equivalence for a map f of arbitrary sets. With S empty, T a singleton, and V cartesian spaces, E_S has no objects while E_T has one; there is no functor E_T to E_S and E_f is not essentially surjective. The auxiliary new categorical-homotopy lemma states only the nonempty finite-set case, which is all that E^n (n >= 0) requires. This is a correction to an auxiliary source claim, not a change to the item statement or a departure from the unit's proof route. No assertion about an empty indiscrete category being equivalent to E^0 is used.
