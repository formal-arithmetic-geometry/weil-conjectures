## Arithmetic input retained for the next worker

Here is the argument of Milne 17.96 that the new statement-only node will split. For x choose a finite subfield k_m containing the values of x on a finite generating set of the coordinate algebra. Then sigma^m(x)=x. For f=Int(x) sigma, induction on j gives f^j=Int(x sigma(x)...sigma^{j-1}(x)) sigma^j. Put y=x sigma(x)...sigma^{m-1}(x). The group A(k_m) is finite: a homomorphism from its finitely generated coordinate algebra is determined by finitely many values in the finite field k_m. Thus y has finite order r>=1. Also sigma^m(y)=y. Iterating f^m=Int(y) sigma^m gives f^{mr}=Int(y^r) sigma^{mr}=sigma^{mr}. Every f-fixed point is therefore sigma^{mr}-fixed. Each generator value then satisfies T^{q^{mr}}-T=0, so has finitely many possibilities; the tuple of generator values determines the point. This works for disconnected and nonreduced A; it only concerns ordinary field-valued points. No Lang surjectivity is used to prove the arithmetic input.
