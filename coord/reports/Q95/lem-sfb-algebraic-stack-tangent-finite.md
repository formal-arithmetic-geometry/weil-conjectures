## Source error

The last paragraph of artin.tex, Tag 07X1, lemma-finite-dimension, asserts that a lift of a ring map B to l[epsilon] is determined by its values on generators of ker(B -> l). This is false without a separability assumption on the residue extension relative to the base. For example let R=F_p(s), let B=l=R[t]/(t^p-s), and use the identity B -> l as the point. This is a finite-type field extension over a Noetherian base, and the point ideal is zero. But for each c in l the map t -> t+c epsilon defines a different R-algebra map B -> l[epsilon], since (t+c epsilon)^p=s. Thus values on the zero ideal do not determine the lift. This is a proof error, not a false item statement. Step 4 instead uses finitely many R-algebra generators of B; their derivative values determine the whole map by the product rule. This proves the source's intended finite-dimensionality assertion without a new hypothesis. No statement correction or weakening was made.
