## Statement and source repairs

STATEMENT-DISPUTED: the displayed sum is outside the imported construction's stated domain: two smooth divisors can have a nonsmooth sum. For T=A^1_k and D1=D2=V(t), the sum is V(t^2), which is not smooth over k. Even two distinct lines meeting in A^2_k have a singular union. The repair defines the same canonical Kummer class for every effective Cartier divisor, via its line bundle with specified trivialization off the divisor; it retains the original smooth-subfamily assertion and makes the sum meaningful. No smoothness of the sum is imposed. The equality is explicitly in the common support H^2_{|D1| union |D2|}; forgetting the different supports implicitly was ill-typed.

The current main-20261015 divisor statement and proof were read in sec-smooth-purity/sk-prop-an, as well as the original master sk-prop-a1-kummer version. They contain the same errors: (f1,f2) is not a frame of the sum (it defines the intersection); the correct equation is f1*f2. Global H^2 classes cannot be compared merely by trivializing a bundle locally. For example the hyperplane line bundle on P^1 has locally zero first Chern class on its two standard affine opens but nonzero global first Chern class with nontrivial prime-to-characteristic finite coefficients. The corrected proof constructs a global relative class and compares the global connecting maps. It does not use the proof of lem-amb-cartier-kummer-map as an unexported interface.

The original citation lem-pur-kummer-additivity states tensor additivity of c1, not multiplicativity of the units Kummer class. We instead use the exact Kummer sequence and additive connecting maps, with the explicit roots coefficient prescription of the already-reviewed def-pur-frame-class. This also avoids the imported additivity node's incorrect tensor expression involving G_m as a coefficient module, and avoids adding the divisibility hypothesis of def-pur-affine-line-datum for ramified coefficient indices. All finite A_{E,n}, n>=1, are covered with exponent ell^n.

The current blueprint moved the item to sk-prop-an, but the shared node still has maintainer-owned unit sk-prop-a1-kummer. That binding is retained. This item is not the key proposition of that unit, so no unit file is changed. The chapter/unit route is preserved, using generic tools declared in split_report.tool_uses. No SGA source is used.
