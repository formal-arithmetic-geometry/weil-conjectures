## Source error

STATEMENT-DISPUTED: the imported statement claims global cohomology vanishing above c over EVERY site object V from a relative cohomological-dimension bound. This is false. Take S = Xbar = Y = Spec(F_q), p the identity, E = Q_l, n = 1, A = F_l, with l different from char(F_q), and c = 0. This satisfies the current definition's finite-type, properness, and invertibility hypotheses. Every p_V is the identity, so all its positive higher direct-image sheaves vanish, for every module sheaf: FullCD(p,A;0) holds. But the cyclic finite etale cover Spec(F_(q^l)) -> Spec(F_q) is a nontrivial torsor for the constant additive group F_l and has no global section. It gives a nonzero element of H^1(Y_proet,F_l). The torsor remains nontrivial on the pro-etale site: a trivialization as a torsor sheaf would give a global section, hence an F_q-algebra homomorphism F_(q^l) -> F_q, which does not exist. The H^1/torsor identification is sites-cohomology.tex, section-h1-torsors (Tag 03AG), lemma-torsors-h1; module and underlying abelian cohomology agree by Tag 03FD. This is a counterexample to the imported node, not an attempted counterexample to the unit's etale-origin bound.

The imported forward proof sets E_2^(a,b) = 0 for b > c, then asserts vanishing in every total degree > c. Terms with a > 0 and b <= c remain, so that inference fails. For weakly contractible bases evaluation is exact and those positive a terms vanish. The imported phrase 'collapses at q=0' also has the indices reversed: the vanishing is in the base cohomology index p > 0.

I corrected the statement to cohomology over every affine weakly contractible W -> V, for every V -> Y. Thus the relative sheaf quantifier over arbitrary V is retained, but the cohomology test is evaluated only where evaluation is exact. This is the intended detection argument in the auxiliary paragraph and the reverse implication, made valid. The comparison is proved using the SAME complex of modules on both sides, without assuming a base-change isomorphism for derived direct image. The title, statement dependencies, proof and split report expose this change. No target or definition is changed. The sole direct user found, thm-sf-fullcd-used-class, contains a loose reference to this item's unrestricted cohomology interpretation; its author/reviewer must use the corrected weakly contractible version. I did not edit another worker's node.
