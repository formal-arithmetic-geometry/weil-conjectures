I checked the split against B–E with the cited node statements and the Stacks sources open. The main issue was that 03D2 defines inverse image of a sectionwise action by finite products, whereas mapMod uses a tensorator. Thus it would be insufficient to call the two actions the same without fixing that tensorator. I kept the full original statement and filled this gap as follows.

**Step 1.** `lem-weil-pbc-right-adjoint-preserves-limits` explicitly supplies both binary-product and terminal comparisons, under the set adjunction already assumed. `lem-weil-pbc-adjunction-lifts-abelian-group-objects` explicitly supplies the finite-product abelian lifts and identifies their unit, counit and Hom bijection with the underlying ones. Its hypotheses hold because L is left exact and G is right adjoint. `sk-def-sfb-sheaf-tensor` supplies the actual sheafified objectwise integer tensor and sheafified constant integer unit. `lem-pc-sites-sheaf-tensor-bilinear-universal` supplies extension and uniqueness, not just a tensor object; the integer specialization uses additivity = integer linearity, with extension through sheafification. `def-weil-pbc-sheafification` states exactly this unique-extension property. Unpacking the canonical lax construction gives the displayed formulas for its tensor pairing and its value on 1; product preservation transports the separate-additivity equations, so the extension exists. This does not assert that evaluation preserves tensor products. The off-unit tensor lemma is a generic tool, declared in `split_report.tool_uses`; its source is exactly the needed Stacks bilinear characterization. It is already Lean-closed as well.

**Step 2.** The cited generic monoidal-mates statement says the oplax and lax structures correspond by adjunction mates. Unpacking that definition gives the explicit adjunct of d used here. The cited lifted-adjunction statement ensures it is the same set unit, and the geometric-morphism definition supplies the set adjunction. Naturality with each product projection gives the displayed product-unit equation. Naturality at the pure pairing then identifies the two SET adjuncts and allows cancellation. I checked the types: p is a set-sheaf morphism, not an additive map from A times B. Accordingly injectivity is used for the set adjunction, never for a nonexistent additive-product morphism. Inverting d uses the stated strong-monoidal hypothesis, not an unstated theorem about every left adjoint. Tensor universality from step 1 then identifies the induced bilinear map uniquely.

**Step 3.** The mate node explicitly states the unit mate formula. Naturality at 1 and the terminal comparison reduce equality to a set-adjunction equality. The injectivity argument proves d0 L(1) = 1 lambda_*; its inverse is the required formula. The sheafification node is used only for its stated universal property: a map from the constant integer presheaf is n times the chosen section, and its sheaf extension is unique. Thus agreement is on the actual integer generator. No preservation of arbitrary constant sheaves is smuggled into the proof.

**Step 4.** `def-sfb-modobj-transport` explicitly states both transported ring multiplication and unit, rather than only defining module objects. `def-weil-pbc-internal-abelian-sheaf-module-equivalence` explicitly states reconstructed multiplication mu(r tensor s), unit eta(1), and the unchanged underlying abelian sheaf. Steps 4 and 5 are marked elementary because they are these written substitutions into definitions, after the substantive tensor normalization is finished.
