For the new enriched-homotopy node I read the original interval argument and Mathlib LeftHomotopy.lean:195–215. Applying this to ba and ab proves the inverse assertion; no fibrant target is needed. The induced H0 functor respects composition because enriched composition is a chain map, so changing a cycle by a boundary changes either composite by a boundary.
