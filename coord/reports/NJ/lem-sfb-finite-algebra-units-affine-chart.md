## Source error

Milne, Algebraic Groups (2017), Proposition 12.60, proof on printed p.250, states the norm should be nonzero for an arbitrary k-algebra R. Take the allowed degree-one field extension A=k and R=k[t]: the element t has nonzero norm t but is not a unit. Also for the zero test ring the unique element is a unit despite being zero. The correct functor-of-points condition is that the norm be a unit. The imported item already uses this correct condition, so no statement dispute or statement change is necessary. The proof generalizes Milne's basis construction to any nonzero finite-dimensional commutative algebra by exhibiting multiplication matrices, instead of invoking separability or a field norm.
