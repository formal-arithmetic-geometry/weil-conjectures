### STATEMENT-DISPUTED: embedding versus isomorphism in the punctual-purity convention

The item and the current blueprint allow an injective field homomorphism `iota : Qlbar -> C`, whereas `def-weil-punctual-weights` starts with a *surjective isomorphism*. At the level of the stated data, an embedding supplies injectivity and ring operations but no inverse or surjectivity witness; consequently it cannot be supplied to an isomorphism-parameterized definition without an additional hypothesis. This is a mathematical type-interface mismatch, not a counterexample to the purity identity. The actual displayed absolute-value condition makes sense for an embedding, and the chapter setup `d-real-setup` explicitly uses embeddings without continuity. I retained every original hypothesis and conclusion and appended the explicit condition for every local Frobenius eigenvalue, stating how the purity convention is read for embeddings. The argument uses only preservation of products and powers, so it proves this full embedding version without adding surjectivity. The root-of-unity lemma as written asks for an isomorphism too; its elementary complex-modulus argument is therefore written directly in step 4 instead of cited with an unmet hypothesis.
