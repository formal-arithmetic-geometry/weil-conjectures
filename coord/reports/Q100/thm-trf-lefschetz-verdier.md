## Source error

STATEMENT-DISPUTED: the current blueprint's final paraphrase calls this a sum “over the fixed points,” although the displayed sum is over connected components and the hypotheses allow positive-dimensional fixed schemes. For example take `X = P^1_k`, `C = X`, `c = diagonal`, `K = A_X` and `u = identity`. Both legs are identities and hence admissible and proper. Then `Fix(c) = X` is proper and connected, so the displayed formula has one term, indexed by all of `P^1_k`. Its set of geometric fixed points is infinite because the algebraic closure of a finite field is infinite. There is no finite sum of individual point terms, and individual points are not open components. The correction preserves the displayed theorem and its proof, and replaces only this false paraphrase. It also states the legitimate point interpretation when the components are reduced points. Binding `u : Lc_2^*K → Rc_1^!K` explicitly merely expands the data already included by `def-trf-correspondence`.
