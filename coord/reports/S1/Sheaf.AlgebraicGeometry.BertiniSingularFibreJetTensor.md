## What changed

Replaced the sorry in `AlgebraicGeometry.bertini_singular_fibre_jet_tensor` by a complete
Lean assembly of the universal equation's value and differential. The theorem's signature
and both public imports are unchanged. Private proof imports supply the hypersurface
criterion, finite local freeness of smooth differentials, reducedness of the singular
scheme, and the two new modules below.

The private lemma `zeroLocus_coefficient_eq_zero` proves that a local equation vanishes
on its actual zero scheme: the affine zero-locus ideal is generated by the coefficient,
and the closed-immersion stalk kernel kills its germ. The second private lemma
`differential_zero_of_nonsmooth_zeroLocus` proves that a nonzero differential contradicts
nonsmoothness, using the existing proved hypersurface criterion. No new geometric
smoothness assumption is imposed.

Added and proved `Scheme.Modules.tensorPullbackSection_eq_zero_of_reduced_factor` in
`Sheaf.AlgebraicGeometry.ReducedPullbackSectionVanishing`. In a local frame it applies
tensor coordinate functionals to the assumed zero residue tensor. Evaluation naturality
and reducedness kill the pulled-back scalar coordinates. The normalized pullback unit
then kills the section, and germ extensionality glues the local equalities. This works
through an arbitrary further, possibly nonreduced, base change. All four private
supporting lemmas in this delivery have complete proofs.

The remaining comparison calculation is stated in the new module
`Sheaf.AlgebraicGeometry.BertiniFibreJetComparison`: it identifies the jet tensor with
the pair consisting of the pulled-back universal equation and its differential. Its
conclusion is an injective comparison map and an identity, without a vanishing assertion
or a singularity criterion. Combining it with the proved geometric vanishing argument
is actual Lean code in the assigned module. This is a strictly partial step of the
original argument rather than a renaming of the tensor-vanishing conclusion.

Updated the assigned node's proof route and added nodes for both new modules. No existing
shared definition, declaration signature, public import, unit, or source-library file
was changed.

## Where the brief, the DAG or earlier work was wrong

No false statement was found. The original plan is correct. It grouped residue detection
on a reduced scheme with the singularity argument; the former is now a general proved
lemma, and the latter is proved directly from the existing hypersurface criterion.
The other unfinished work is the independent geometric comparison identity. Neither
new statement assumes that tensor vanishing, and the unit route is unchanged.

Edge cases checked in the statements and arguments: an empty singular fibre, an empty
index set, cotangent rank zero, arbitrary finite local ranks, an empty inverse-image
open, and a nonreduced scheme after the reduced factor. Reducedness is required only of
the intermediate scheme, so the actual singular fibre is never assumed reduced.
