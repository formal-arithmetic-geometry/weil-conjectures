## Source error

Milne I Proposition 14.4(a), p.62, ends its compactness argument by saying that End(A) tensor R is compact. For a positive-dimensional elliptic curve over C, End(A) contains the integer multiplication maps and its real scalar extension has a real line, so this finite-dimensional real vector space is not compact. The compact object intended is the positive trace-form level set (or its closed sublevel ellipsoid). The displayed norm bound is correct. We repair this inference using the rational positive-form lattice-sublevel lemma and do not alter the item's theorem. This is a source-proof correction, not a STATEMENT-DISPUTED theorem.
