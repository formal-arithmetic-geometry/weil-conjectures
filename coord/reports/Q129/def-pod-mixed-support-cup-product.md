## Source error

STATEMENT-DISPUTED: the unqualified phrase “graded-commutative” is not a typed equality of two instances of the displayed mixed-support map. After exchanging RΓ_c(X,K) and RΓ(X,L), the compactly supported factor is on the right, whereas the displayed definition takes it on the left. For nonproper X, one cannot put the swapped arguments into the same type by identifying RΓ_c with RΓ. The correction introduces the right-support version by the two canonical symmetries. Its elementary identity is
RΓ_c(σ_{K,L}) ∘ μ_{K,L} = μ^r_{L,K} ∘ σ_{RΓ_c(K),RΓ(L)},
since the two consecutive source symmetries cancel. On homogeneous cohomology classes it gives H_c(σ)(x cup_c y) = (-1)^(ij) (y cup_c^r x). This is the usual meaning of the source's graded sign; the identity itself is elementary, so I created no node for it. All symmetry notation and its cochain sign are defined inline in the item.

The geometry is the current fixed setting sk-def-set: smooth, separated finite type and geometrically connected, with no properness requirement or ambient exceptional-adjoint assumption. There is an inherited discrepancy in def-pod-conventions, which still includes ambient exceptional admissibility; the current sk-def-set and sk-def-ops explicitly remove it, and the defining composite here uses only the ordinary pullback/direct-image adjunction and compact-support pushforward. The new definition does not assume the false unrestricted ambient exceptional right adjoint. This does not replace any unit proof route: the item is an auxiliary definition and is not the key node of sk-thm-sf-package, so the unit's realized fields are untouched.
