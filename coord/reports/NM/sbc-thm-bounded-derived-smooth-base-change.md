## STATEMENT-DISPUTED: restore the standing coefficient hypotheses

The imported text quantifies over bounded constructible Lambda-complexes without specifying a positive annihilator invertible on S. Its proof nevertheless introduces such an N. The rejected Lean declaration also explicitly asks for N != 0, (N : Lambda) = 0, and IsUnit (N : Gamma(S, top)); those assumptions cannot be inferred from bounded constructibility. In particular Lambda = F_p, S = Spec(F_p), K = F_p[0] is bounded constructible, but every positive integer annihilating its stalks is divisible by p and is not invertible on S. Thus the original proof's application of allowable-torsion smooth base change fails its hypothesis check.

There is an actual counterexample without invertibility. Let k be algebraically closed of characteristic p, S = Spec(k), T = Spec(k(t)), X = A^1_k with coordinate x, Y = A^1_{k(t)}, f the smooth structure map and g the affine field-extension map. Take Lambda = F_p and K = F_p[0]. At the geometric point x = 0 the target of degree-one base change contains the germ of the Artin--Schreier torsor z^p-z = tx. This germ restricts trivially along x = 0, so if it came from H^1(k(t),F_p), that class would be zero. But its germ is nonzero: on every pointed etale neighbourhood U of 0 take an integral component through the point. In its function field k(U)(t), x is nonzero, and tx has a pole of order one at t = infinity. A rational function a^p-a with a pole has pole order divisible by p; one with no pole cannot equal tx either. Thus the torsor has no section on U times_k Spec(k(t)), and it stays nontrivial in the stalk. The degree-one comparison is not surjective. The Artin--Schreier calculation uses Stacks Tag 0A3J.

The corrected statement spells out exactly the chapter's standing convention, node sbc-def-coefficient-conventions: Lambda finite commutative, N positive, N Lambda = 0, and N invertible on S. It retains the same square, smoothness, qcqs hypothesis, bounded constructible input and ambient-derived isomorphism conclusion. This is restoration of source intent, not a weakening to accommodate the rejected attachment. Finite Lambda is also the actual scope of def-weil-pbc-constructible-complexes; I corrected the earlier draft's unsupported arbitrary-ring quantification and removed its unbound Lean expression involving hK. The clause about endpoints explicitly prevents interpreting the assertion as preservation of bounded constructibility by arbitrary qcqs g.
