## Errors found and corrected

The imported item statement agrees with Kerodon 03X7 and 00UA and remains byte-for-byte unchanged. There is no dispute of that statement.

STATEMENT-DISPUTED (discarded earlier sandbox draft only): `lem-cbc-kan-fibrant-replacement` falsely asserted that a trivial cofibration from an arbitrary simplicial set to a Kan complex has a simplicial homotopy retraction. Cofibrancy of the domain does not make it fibrant and supplies no lift against its terminal map. For a concrete obstruction, take the simplicial circle `K = Δ¹/∂Δ¹` and any Kan replacement `K → R`. Every edge of a Kan complex has an inverse witnessed by a 2-simplex. The only invertible edge in this simplicial circle is its degenerate edge: its nondegenerate loop has no inverse-triangle 2-simplex. Thus any simplicial map `R → K` sends all edges to the degenerate edge, so induces the zero map on the first homology of the realizations. It cannot give a homotopy retraction of a weak-equivalence replacement of this circle. I removed the false node and every invocation of these retractions.

A second issue is a dependency cycle in the proposed model-category route. The existing `lem-coef-kan-quillen-right-proper` reaches this item through `lem-cbc-enhanced-functor-cone-calculus`, `lem-cbc-simplicial-composition-spine`, and `lem-cbc-kan-mapping-homotopy-invariance`. Citing it here, even only its model-structure clause, closes a DAG cycle. The general localization/mapping-class nodes also reach that route. I did not edit those existing nodes. The replacement below the unit uses topological Whitehead and realization comparison directly; it neither changes the compact-support unit nor changes any coefficient category or base-change arrow.

The earlier report claimed that the model-structure theorem had been added to all relevant steps, but the JSON did not contain that citation. I replaced that report and proof in full.
