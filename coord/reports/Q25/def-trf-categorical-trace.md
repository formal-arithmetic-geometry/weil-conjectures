## Statement correction

STATEMENT-DISPUTED: bounded projective complexes with chain maps do not form the derived perfect category as stated literally in the import. For example, the two-term complex `A --id--> A` is contractible: its identity chain map is nonzero before quotienting but zero in the homotopy and derived categories. The correction takes the full subcategory `Perf(A)` of `D(A)`, represented by bounded projective complexes with homotopy classes of chain maps, as guaranteed by the existing `lem-pc-ring-derived-map-representative`.

There is also a genuine notation conflict with `def-weil-point-finite-cohomology-complexes`: that node defines `D^b_fin(A)` by bounded finite cohomology, whereas the trace source deliberately uses it for perfect complexes. For `E=Q_3`, `n=2`, `A=Z/9`, the degree-zero module `Z/3` has finite bounded cohomology but is not perfect: the projective resolution with differential multiplication by 3 has `Tor_i^A(Z/3,Z/3)=Z/3` for every nonnegative i. The repaired definition retains the trace chapter's legacy notation explicitly as `Perf(A)` and distinguishes the ambient finite-cohomology category; it does not extend the trace to all finite-cohomology objects. Citers of this definition retain the intended perfect domain. No target is changed.

The original display of evaluation and coevaluation did not specify the maps. I supplied the total-Hom differential, Koszul symmetry and finite dual-frame formulas. The frame comes from the already existing ordinary-ring splitting package, so a finite projective module is never assumed to have a basis. All claims of triangle identities and representative independence remain with the existing forward pointer `lem-trf-chain-supertrace`; that theorem is not a dependency of the definition. The source's explanatory converse characterization of dualizable objects is not used as an unproved premise of the construction. The actual perfect domain and trace composite are preserved.

The old direct `def-weil-derived-tensor` citation was specifically about pro-etale sheaves, rather than ordinary modules. It is replaced by the shared total tensor applied to the explicitly described one-object site and by the existing module K-flatness criterion. The scheme point/fibre construction is not used to define a ring trace. All original import flags, blueprint metadata, pointers and audits are preserved.
