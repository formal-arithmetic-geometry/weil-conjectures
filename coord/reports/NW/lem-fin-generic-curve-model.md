## Source error

The imported blueprint's paragraph 2 asserts that generators f_j with f_j^(N_j)=0 generate an ideal whose max(N_j)-th power vanishes. This is false: in k[x,y]/(x^2,y^2), each generator has square zero, but (x,y)^2 contains the nonzero element xy. The valid bound is 1 + sum_j(N_j-1). Step 5 records this correction and uses the stronger direct argument: each descended element is nilpotent by tensor injectivity, and the quotient is reduced by the same injectivity. The lemma's statement is unaffected; there is no STATEMENT-DISPUTED statement change.

The imported smoothness paragraphs also cite def-sbc-smooth-morphisms for a Jacobian criterion it does not state. I removed that inference rather than interpreting the definition as such a theorem.
