## Arguments retained for the new queued nodes

These notes preserve the arguments removed from the parent; the new node files themselves have statements only.

- **Color coslice components.** The only inert endomorphism of `[1]` is its identity, so its fiber is full. In a simplex of the color coslice, all remaining vertices lie over `[1]` and all arrows among them project to identities. Consequently the base arrow from `[n]` to `[1]` is constant throughout that simplex and is one of the `n` consecutive-pair projections. This identifies the simplices degreewise with the displayed disjoint union, respecting faces, degeneracies and target projection. Each summand is exactly the lift category in `lem-coef-infinity-cocartesian-composition-initiality`, which supplies its quasicategory structure and the chosen initial cocartesian lift.
- **Relative tuple cone.** Choose a Segal preimage of the prescribed tuple and compose its cocartesian projections with the chosen fiber equivalences to the exact targets. The relative mapping-product axiom of the monoidal definition, tested fiberwise over the discrete base mapping sets, gives the constant-source test square; the limit dual of `lem-coef-infinity-relative-cone-constant-test` identifies this with the join-cone definition. Postcomposition with the fiber equivalences preserves it by the dual of clause (1) of `lem-coef-infinity-relative-cone-equivalence`. Conversely compare any specified relative-limit cone with this tuple cone over the identity base cone, fixing the boundary. The relative universal property makes the comparison spaces contractible in both directions. Their composites are homotopic to identities, so the apex comparison is a fiber equivalence and all cone edges are cocartesian by the mapping criterion.
- **Detection by target colors.** Factor the edge through a chosen cocartesian lift over its inert base map, obtaining a residual map in the target fiber, using the object case of `lem-coef-infinity-pointwise-cocartesian-transport`. Project that map to every target color. The resulting fiber comparisons relate two cocartesian lifts of the same color base arrow with the same source; the initiality/comparison clause of `lem-coef-infinity-cocartesian-composition-initiality` makes each comparison an equivalence. The Segal equivalence identifies these as the components of the residual map, so that map is an equivalence. Composition with the chosen cocartesian lift is therefore cocartesian by the mapping criterion. The reverse implication is cocartesian composition. With no target colors the Segal fiber is equivalent to a point and the same argument applies.
