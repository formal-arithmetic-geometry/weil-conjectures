## Statement and source errors

STATEMENT-DISPUTED: the imported intrinsic bound `2 dim Xbar` is not a nonnegative FullCD parameter when Xbar is empty. The DAG's `def-kun-topological-krull-dimension` sets `dim(empty) = -infinity`, while `def-sf-fullcd-class` permits only nonnegative integer parameters. The counterexample is the proper identity of the empty finite-type k-scheme, with d = 0. The corrected statement retains FullCD at 2d in every case, states the intrinsic 2dim bound for nonempty source, and uses bound 0 for empty source. The latter follows from the existing uniform theorem with d = 0; no new hypothesis is added to the main assertion. The corrected statement explicitly names the universal 2d bound; the maintainer-owned title is retained from the current base.

The imported proof also falsely identifies all étale-origin sheaves with constructible sheaves. Take k algebraically closed, A a nonzero finite coefficient stage (for example F_l), and the constant étale sheaf with value the infinite module direct sum over positive integers of A on Spec k. Its comparison pullback is of étale origin but has an infinite stalk, hence is not constructible. Stacks Tag 09AK, `proetale.tex`, `lemma-compare-constructible`, compares the two *constructible* categories; it does not make every origin sheaf constructible. The already reviewed class definitions correctly retain all origin sheaves. I removed the invalid inference from the item's proof and explicitly retained that class in the statement.

The imported proof spoke as if restriction made a quantifier over original-source sheaves equivalent to a quantifier over all origin sheaves on the changed source. It does not. Both the corrected definition and the existing uniform theorem quantify over original-source sheaves and their pullbacks. Steps 2–3 now use that precise assertion. Neither restriction closure nor a new theorem for arbitrary changed-source coefficients is needed. In particular I do not use the overstrong dimension assertion in the unit text: an arbitrary pro-étale site object need not be finite type over k. The existing used-class theorem handles arbitrary V via its already recorded proper-base-change route.
