## Argument retained for the new statement-only node

For R Noetherian and X finite type over Spec R, take a finite affine cover Spec C_j with each C_j Noetherian. Put U=R minus p. The ring of the pulled-back chart is U^{-1}C_j. Since X_p is integral, each such ring is either zero or a domain. The kernel of C_j -> U^{-1}C_j is a finitely generated ideal: select finite generators and multiply their U-annihilators. After inverting that product a_j outside p, the map (C_j)_{a_j} -> U^{-1}C_j is injective. If the target is zero, the kernel contains 1, so this also kills that chart. If it is nonzero, its subring (C_j)_{a_j} is a nonzero domain. Use the product of all a_j. At least one chart survives because X_p is nonempty. Any two surviving charts have nonempty intersection: their pullbacks are nonempty opens in the same integral X_p, hence intersect, and a point of that pullback supplies a point of the intersection upstairs. These integral affine opens with pairwise nonempty intersections give an irreducible scheme; the domain chart cover also gives reducedness. The integral criterion proves X_a integral. This argument explains the Noetherian hypothesis, including charts that disappear, and works for a non-domain base and nonseparated X. It is substantially more than the two-line diagram assembly, so it is retained as the sole new lemma.
