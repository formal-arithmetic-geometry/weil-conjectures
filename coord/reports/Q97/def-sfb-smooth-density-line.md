## Construction audit

The item is a definition, so its JSON correctly has `proof: []`, `proof_deps: []`, and `proof_origin: null`. The following checks explain the construction and do not turn either unsplit new node into a split theorem.

1. The existing manifold node gives smooth transitions on open subsets of real Euclidean space. The new Jacobian lemma gives positive smooth g_xy and smooth reciprocal, g_xx = 1, and g_xz = g_yz g_xy at the same point of N. Therefore T_xy(a) = a / g_xy gives exactly the core's coefficient transition, with T_yz T_xy = T_xz. Scalar multiplication identifies these maps with smooth maps into the continuous linear endomorphisms of the real line. The arbitrary off-overlap extension can be zero. Choosing a containing chart at each point requires no continuous selection.

2. The core node actually constructs a topological bundle and gives smoothness of that bundle; the existing definition of a smooth vector bundle alone would not justify gluing. For a choice sigma(p), the explicit map from the quotient to the core fibre sends [x,p,a] to (p, a/g_(x,sigma(p))(p)). On a quotient relation a = b g_xy, the cocycle gives a/g_(x,sigma) = b/g_(y,sigma), so this is well-defined. Its inverse is (p,v) mapped to [sigma(p),p,v]. The i-th local coefficient map of this identification is precisely a/g_xi, by the core's stated local-trivialization formula. It is a linear homeomorphism on each chart: composing the continuous core chart inverse with the quotient inclusion gives the continuous inverse, while the forward map is continuous on every disjoint-union piece by the smooth transition formula and hence on the quotient. Thus the quotient topology and the topology supplied by the core agree, and the core smooth atlas gives the requested smooth line. This comparison is direct substitution into the two definitions, not an uncited gluing theorem.

3. The old vector-bundle node supplies the rank-one terminology, and the old smooth-section node supplies exactly the last sentence defining smooth densities. No orientation is used: all chart Jacobians may have either sign before taking their absolute values.

The proof to pursue when the new Jacobian lemma itself is split is the ordinary chain rule for the three chart transitions. Differentiating each transition composed with its inverse gives inverse derivative matrices. Hence the determinant is nonzero; the derivative matrix entries are smooth, so its determinant is smooth, and absolute value is smooth away from zero. Reciprocal is smooth away from zero as well. Apply determinant multiplicativity and absolute-value multiplicativity to the chain rule to obtain the triple identity, and take the identity/inverse transitions for the other two identities. The new node contains only this result's statement, as required; the argument is retained here for its later worker.
