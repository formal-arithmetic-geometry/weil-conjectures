## Statement dispute and other corrections

STATEMENT-DISPUTED: for X empty the only open subscheme U is empty, and the claimed inequality reads dim(empty) < dim(empty). This is false under both the Stacks convention -infinity and the -1 convention used elsewhere in the blueprint. Stacks [0055](https://stacks.math.columbia.edu/tag/0055) explicitly gives dimension -infinity exactly for the empty space. The imported proof's opening sentence, “If X is empty, take U=X”, therefore cannot prove its original conclusion. The corrected statement separates the empty case, retaining the full strict inequality whenever X is nonempty. It also states the existing finite commutative coefficient-ring convention explicitly: the imported argument already cited `def-weil-pbc-constructible-complexes`, which defines precisely those coefficients. No rational, adic, or Weil sheaf is substituted.

The original statement dependencies omitted the constructibility/lisse definition and dimension definition while citing only the scheme-conventions bundle. The replacement names the actual definitions used. The original paragraph silently used finite-type Noetherianity and finite-dimensional dimension drop; those facts are now cited statements. The finite-components lemma is no longer needed directly because generic constancy and strict dimension drop are existing general tools. This changes only the proof of this node, not the chapter or the unit. The unit's four steps concern purity of constituents, exterior powers and determinant weights; they do not prescribe a componentwise proof of this auxiliary constructibility lemma.

The external tag of the reused node `lem-sc-hilbert-nowhere-dense-dimension-drop` needs care: [02P2](https://stacks.math.columbia.edu/tag/02P2) concerns meromorphic sections and nowhere-dense support; it does **not** state the general dimension-drop theorem. I report this source-attribution problem rather than changing that other worker's node. The node's actual statement is the general strict-drop theorem needed here and is mathematically correct. Its justification uses components and the chain definition, supported by [004W](https://stacks.math.columbia.edu/tag/004W), [0052](https://stacks.math.columbia.edu/tag/0052), and 0055: locally Noetherian components are locally finite; each component has a nonempty open piece disjoint from the others. A nowhere-dense closed set cannot contain such a component. Every irreducible closed chain in the closed subset extends strictly by an ambient component, so its length is at most d-1. This also proves the zero-dimensional case by contradiction from a putative point. I have not represented 02P2 as a direct source of this theorem in the delivered proof.
