## Argument retained for the new statement-only node

For a future worker, this is exactly the calculation read in divisors.tex, Tag 0BCR. Put K_n=Q[f^n], K_0=0, and l_n=length(K_n). Multiplication by f^n embeds K_(n+1)/K_n into K_1, so induction and length additivity show l_n is finite. The inclusions K_n subset K_(n+1) give l_n <= l_(n+1). The kernel of K_n -> Q/fQ is fK_(n+1): if q=fx and f^n q=0 then x lies in K_(n+1), and conversely. The sequence 0 -> K_1 -> K_(n+1) -> fK_(n+1) -> 0 gives length(fK_(n+1))=l_(n+1)-l. Consequently the image I_n of K_n in Q/fQ has length l_n-l_(n+1)+l <= l. The I_n form an increasing union equal to Q/fQ by power torsion. Any finite strictly increasing chain of submodules in that union has a witness for each strict inclusion; all finitely many witnesses lie in one I_n. Intersecting the chain with I_n preserves strictness, so the chain has length <= l. The definition of length now gives the claimed bound. This argument is not placed inside the new node's statement or proof fields.
