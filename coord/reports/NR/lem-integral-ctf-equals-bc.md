## Statement corrected

STATEMENT-DISPUTED: the imported statement mixes incompatible definitions. The current item and proof, its current unit opening paragraph, and the current parent `_section.md` in `sk-def-sfb-constructible` were read together. The unit says explicitly that a constructible integral sheaf is, on strata, a scalar finitely presented module tensored with the coefficient sheaf. The item proof begins with exactly that scalar local model. However, its bracketed `def-sfb-constructible-module` only requires arbitrary local finite presentations, and `det-def-sfb-bounded-constructible` uses that broader predicate. A local presentation matrix over the coefficient sheaf need not have scalar entries. The current local-model node explicitly states that its converse to local finite presentation fails.

There is an explicit qcqs counterexample to identifying those predicates, already exhibited by `lean/Sheaf/AlgebraicGeometry/FiniteConstantLocalModel.lean:1141ff`: let S be the one-point compactification N∪{∞}, X=Spec LC(S,Q), and use continuous Q_2 coefficients. The function t(n)=2^n, t(∞)=0 gives a one-by-one presentation of its cokernel. Geometric fibre dimensions are 0 at finite n and 1 at ∞. A finite constant local model forces this dimension function to be locally constant (take the finite compact-image subcover), which it is not. On this Stone scheme constructible subsets are clopen; the stratum of any finite constructible partition containing ∞ still contains all but finitely many n. The same obstruction survives that stratum, so a finite stratification does not repair this example. This disproves the identification of the two constructibility predicates; it is not presented as a counterexample to every possible general-lfp Tor bound.

There is a separate type/convention failure: `def-weil-finite-tor-amplitude` defines integral finite Tor by uniform finite reductions on a derived-complete category (and has an invertibility setup), and defines the rational category through older scalar localization/common stages. It does not define the raw tensor test for all degree-zero modules of the uncompleted condensed category used in the displayed conclusion. Thus the imported expression cannot be justified by that reference with the objects in the item. I replaced it with `det-def-sfb-constructible-tor-amplitude`, which states precisely the raw tensor test and the scalar-model Dbc/Dctf definitions.

The corrected statement explicitly fixes the finite constant local model convention of the current unit and parent definition, the pulled-back coefficient rings, and the ordinary uncompleted derived category. It retains qcqs X without adding Noetherianity or invertibility, allows integral torsion, retains both module bounds and both complex bounds (including the sharper field [a,b]), and retains all scalar and constant-sheaf counterexamples and finite-ring thickness. It makes the examples' scalar/Spec k interpretation and the finite-ring quantifiers explicit. This is a source-intent correction, not an assertion that the general-lfp predicates are equivalent on arbitrary qcqs schemes. The source contains genuinely conflicting references, and the distinction must remain visible to the maintainer.
