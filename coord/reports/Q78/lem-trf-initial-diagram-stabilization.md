## Proof idea for the new combinatorial node

This explanation is for its later worker; the new node itself has no proof. Set p=r+1. For a quotient exception beta, let x=alpha_i+beta. Since x belongs to its own ordered region but x+e_p does not, there is an earlier vertex a=alpha_h, h<i, dividing x+e_p but not x. Necessarily a_p=x_p+1, so beta_p<M. For every t>p, monotonicity puts a'=a-a_p e_p+a_p e_t in D. If beta_t>=M, then a' divides x: at p its coordinate is zero; at t, a'_t<=|a|<=M<=x_t; all other coordinates were already bounded by x. Some vertex delta divides a'. This delta is earlier than alpha_i. Indeed |delta|<=|a|<=|alpha_i|. If equality holds throughout, delta=a', and a and alpha_i have equal degree. Since beta vanishes before p, a_j<=alpha_i,j there, whereas a_p>alpha_i,p. For a to precede alpha_i, its first strict lexicographic inequality must therefore occur before p. Moving coordinate p leaves that inequality intact, so a' also precedes alpha_i. Thus an earlier vertex divides x, a contradiction. Hence every beta_t<M for t>p as well. Earlier beta coordinates are zero by definition of the face.

For a remainder exception gamma, take a vertex a dividing gamma+e_p but not gamma, so a_p=gamma_p+1 and gamma_p<M. If gamma_t>=M for t>p, the same moved vector a' belongs to D and divides gamma, contradicting gamma outside D. This proves the claimed finite box, including no vertices and the zero vertex. It is a ring-free support result, not the item's polynomial spanning conclusion. It is the elementary-coordinate content behind BM Lemma 8.2 and Remarks 8.4, made quantitative here.
