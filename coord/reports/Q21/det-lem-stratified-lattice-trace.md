## Source issue in an existing auxiliary node

The statement of `lem-fet-locally-trivial` promises one finite set of sheets over one surjective étale cover of the entire base. That is false without constant degree: take a base consisting of two geometric points, and a finite étale surjection with one point above the first and two above the second. Any surjective base change still has fibres of sizes one and two, whereas a product with one finite set has the same size everywhere. Its recorded Lean theorem at line 36 is instead pointwise, and Stacks 04HN is pointwise too. This delivery changes neither that node nor its audit; it uses the correct existing pointwise node. The statement of the assigned item is true and does not need a STATEMENT-DISPUTED correction.
