## Source error — STATEMENT-DISPUTED

The main-20261015 statement (sec-six-functors-basics/sk-prop-a1-kummer/lem-pur-kummer-additivity.md) calls the roots of a trivialization of a line bundle an A-torsor and places the line-bundle class in H^1(G_m tensor_Z A). These are type errors. The frame torsor is a G_m-torsor. Roots of a unit give a mu_m-torsor in degree one; the boundary of a line-bundle class lies in degree two. Moreover the m-power map on the etale units sheaf is surjective by Stacks 03PL. Therefore G_m/mG_m=0 as an etale sheaf. For A=Z/m, G_m tensor_Z A is zero, so the proposed source group is zero. This loses the ordinary Kummer class; for example on P^1_k the class of O(1) is not m-divisible in Pic(P^1_k)=Z, and the Kummer exact sequence maps it nontrivially to H^2(mu_m) when m>1.

I corrected the statement faithfully to its intended Kummer argument: frame-torsor class in H^1(G_m), ordinary connecting homomorphism to H^2(mu_m), then coefficient insertion z maps to z tensor 1. The resulting etale A-module class is pulled to the specified pro-etale Tate twist. I did not tensor the Kummer sequence with A. I retained every finite level n>=1: choose any N with ell^N A=0 (N=n suffices). No divisibility assumption e|n was added. The old datum node now imposes e|n, so citing it as the general line-bundle definition would silently restrict the theorem. The replacement uses the existing arbitrary-base Kummer node and the general twist-reduction theorem instead. Exponent independence is proved explicitly.

The original proof only named definitions for non-elementary inputs. I replaced that with actual statement citations. In particular the curve-only lem-sc-h1-gm-pic and lem-sc-h1-gm-pic-pullback were not used on arbitrary T. The arbitrary-scheme line-bundle torsor and H^1 functoriality nodes already supply precisely what is needed.
