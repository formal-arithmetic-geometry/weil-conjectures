## Source error

STATEMENT-DISPUTED: the imported unit summary leaves the coefficient sheaf unspecified and treats all higher-stage small categories as full subcategories of an ordinary constant-coefficient derived category. Its own detailed coefficient sources specify different constructions. This same ambiguity was already corrected and independently reviewed in `def-sf-categories` (Q63, 2026-10-16). I reused that definition rather than creating a competing correction.

The source type check is explicit. In the current main-20261015 blueprint, `sec-proetale-coefficients/sk-prop-integral-criterion/def-weil-completed-integral-coefficients.md` defines the inverse limit of finite constant sheaves and expressly excludes the discrete constant integral sheaf. Its companion `def-weil-derived-complete-integral-detailed.md` requires derived completeness and one cohomological interval for all reductions. The current `sk-def-sf-operations/def-weil-rationalization-karoubi.md` defines the rational category by changing integral Hom groups to their tensor products with E. `def-weil-algebraically-closed-coefficients.md` defines objects as finite-field-stage pairs and morphisms as common-stage colimits. Neither construction is literally the asserted subtype of ordinary constant-field complexes without further realization data.

A concrete small case distinguishes the integral sheaves. For a geometric point T in characteristic different from ell, use the pro-etale object indexed by the profinite set S = Z_ell, obtained from the finite disjoint unions indexed by Z/ell^j. Sections of the discrete constant Z_ell sheaf are locally constant functions S -> Z_ell. Sections of the completed sheaf include the compatible residue-coordinate functions s -> s mod ell^j. Their limit is the identity S -> Z_ell, which is not locally constant. Thus replacing one coefficient sheaf by the other changes actual sections. Also, a nonzero integral object killed by a power of the uniformizer has zero identity after scalar localization, so merely retaining its integral Hom groups does not construct the rational category.

The correction keeps the ordinary ambient categories for a specified ring sheaf on either site, states allowable torsion on cohomology stalks, and retains the finite-stage constructible, finite-Tor and cohomological-interval full subcategories. It spells out the already reviewed completed-integral, rational and common-stage meanings, including field-stage Dctf = Dbc by definition. The invertibility proviso is exactly the scope of the finite-Tor conventions already named by the source. No equivalence between coefficient models, preservation theorem, or existence of a t-structure on an arbitrary scheme is added.

The imported statement dependency `sk-def-sf-operations` is not used to define any category here. The item now depends on the existing category definition, not on the later operations. The source/unit text and imported flags are preserved. Only the unit's allowed realization fields change.
