I also read the Noetherian Stein-factorization statement Tag 03H0 (`theorem-stein-factorization-Noetherian`) for the geometric boundary input.

The no-isolated-component lemma makes explicit an auxiliary geometric input that Temkin's stable-subcurve sentence leaves implicit. Tag 03H0 alone does not state this lemma; I do not use it as if it did. The new node is the required separate statement, not a claim of an existing Stacks theorem with stronger conclusions. The geometric reason is that a proper whole connected nodal fibre component can be followed etale locally as a proper component of the flat geometrically reduced family. After choosing an affine neighbourhood of its putative contracted image, properness removes the complement of that neighbourhood on a neighbourhood of the base point. Its positive-dimensional generic proper curve would then map isomorphically into an affine generic target curve, which is impossible. This is the boundary phenomenon used here; none of the existing Stein-factorization nodes states it. Its later split must supply the component-spreading input rather than assert that it is elementary.

I added the etale definition and the exact unramified-over-field criterion for the marking's reduced multiplicity-one structure instead of silently using a reducedness theorem. In step 2 the nodal lci criterion applies to every residue-field fibre, the complete-intersection definition provides a principal global-CI neighbourhood, the syntomic-at-prime node has exactly the local flatness and finite-presentation hypotheses available, and the relative-CI regular-sequence node gives genuine regular embeddings. Its general-dimension statement is a coherent adjunction theorem, not an etale-coefficient purity theorem and not a marked-curve degree assertion.
