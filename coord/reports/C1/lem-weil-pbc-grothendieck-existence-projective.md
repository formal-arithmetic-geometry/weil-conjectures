checked every cited node against the corresponding argument:

1. **Projective and ample setup (0885, 01W9, 01Q1).** The closed immersion

   graded-vanishing, and 0884 nodes state exactly those three links; the
   parent’s Step 3 cites the 0884 node and its statement names both children.
4. **Global generation (01Q3).** For the coherent first level and the ample
   invertible sheaf, Proposition 01Q3 gives a sufficiently positive twist
   generated by finitely many global sections.  The new global-generation
   node has exactly these hypotheses and conclusion, and the parent chooses
   `d` above the Step 3 bound as the source does.
5. **Compatible lifts (0885 proof).** Tensoring the successive short exact
   sequences by an invertible sheaf preserves exactness.  Step 3 kills the

   inductively to a compatible system.  This is the source paragraph beginning

6. **Epimorphism modulo the ideal (087Y).** The compatible sections define

   surjectivity node has exactly that statement and the parent cites it.
