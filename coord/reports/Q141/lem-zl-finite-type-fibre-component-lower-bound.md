## Maintainer review correction

The delivered conclusion contained the clause `e ≤ d` (that is, dim(B/P) ≤ dim C), which the
node's statement does not assert (it is derived in proof step 2), so the conclusion was stronger
than the node (H3). The maintainer's reviewer removed that clause and wrote the component bound
additively, `(d : WithBot ℕ∞) ≤ topologicalKrullDim W + (e : WithBot ℕ∞)`. This is exactly the
integer inequality dim W ≥ dim C - dim(B/P) and involves no truncated subtraction (`WithBot ℕ∞`
has no `Sub`, so `(d - e : WithBot ℕ∞)` was the cast of a natural-number subtraction).
The theorem docstring now carries the node's proof steps 1-7. Hypotheses and objects are
unchanged.
