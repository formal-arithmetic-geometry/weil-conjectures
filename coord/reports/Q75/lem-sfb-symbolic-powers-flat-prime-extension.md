## Source error

Stacks `literature/stacks-project/algebra.tex`, Tag 0BC0, `lemma-symbolic-power-flat-extension`, ends with “Thus f acts invertibly as desired.” This is false as written. Take a field R=k, p=0, S=k[z], q=0, n=1 and f=z. Then the filtered module is k[z], and multiplication by z is injective but not surjective. The preceding part of the source only asks that f be a nonzerodivisor, and this is exactly what the vector-space-basis argument proves. I replaced invertibility by injectivity throughout the proof. The theorem and the item's statement do not need correction. There is no STATEMENT-DISPUTED assertion about the imported statement.
