The finite degree assumption gives `Module.Finite k K`. If every element of `K` is
separable over `k`, Mathlib supplies separability and algebraicity for every
intermediate field. For each intermediate field, the empty set is algebraically

extension is empty. Separability persists on extending the base to the intermediate
field generated by this empty basis. Thus every finitely generated intermediate
field is separably generated, contradicting the assumed nonseparability.
