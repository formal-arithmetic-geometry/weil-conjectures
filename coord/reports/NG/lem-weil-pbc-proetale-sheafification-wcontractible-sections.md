## Statement clarification and disputed inference
STATEMENT-DISPUTED: the imported wording uses a profinite-point functor $a$ on the $X$-site without specifying its codomain. The cited existing node defines $a$ only on the Spec Z site, so for general $X$ that direct Kan-extension phrase is not typed as written. We replaced it with the source's $a_X(S)=X[S]$ and explicit coefficient topology, preserving the intended assertion and all naturalities. Its sole direct citer, lem-weil-pbc-condensed-point-basis-evaluation, already uses exactly $X[S]$ in step 2 and is compatible with this clarification; it is not edited.
The split's additional maximal-sieve inference is false: take $X=U=\operatorname{Spec}(k)\amalg\operatorname{Spec}(k)$ for a separably closed field $k$. This is a weakly contractible affine, but the covering sieve generated by the two clopen inclusions contains neither $\mathrm{id}_U$ nor an arrow through a single summand that equals it. A constant two-element presheaf would acquire four sections over $U$ after sheafification. The actual condensed Kan presheaf already carries the four-section product value, which explains why finite-coproduct preservation is essential. At the empty scheme arbitrary set presheaves likewise need not have the terminal value, whereas the actual Kan presheaf does.
