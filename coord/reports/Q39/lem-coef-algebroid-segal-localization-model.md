## Source error

STATEMENT-DISPUTED (source formulation, already corrected in the imported item): in Proposition 8.5, locality of the total degree-one presheaf need not express locality of each hom presheaf. Take C the terminal monoidal category, so P(C) is spaces, and S the single map from the empty space to the point. This is monoidally compatible: its local category is the terminal category, so every map is inverted by reflection. The empty algebroid has no object pairs, so all its homs are S-local vacuously, but its total edge space is empty, which is not S-local. Hence the total-edge version excludes a valid localized algebroid. This counterexample uses a monoidally compatible S, not an arbitrary incompatible test.

The raw-J replacement also fails the fixed-endpoint formula already for phi empty. J(empty) is initial and its mapping space into any Z is a point. The required family over Z_0 squared has total space Z_0 squared when phi is empty; it is empty if Z has no objects and can have many components otherwise. E(empty)=v coproduct v gives precisely that mapping space. Step 6 derives the corrected formula by mapping the actual pushout to a pullback. No target statement was weakened or modified.
