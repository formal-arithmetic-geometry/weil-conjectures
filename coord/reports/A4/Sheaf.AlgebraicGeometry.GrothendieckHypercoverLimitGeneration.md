## Where the brief, the DAG or earlier work was wrong

The original DAG explicitly called for a categorical generalization of
abelian-group section continuity, but did not have a declaration stating that
generalization. It cannot be obtained by applying the existing elementwise
theorem to arbitrary Grothendieck coefficients. The new degree-zero statement
isolates precisely this missing part; its source is identified as a categorical
generalization, not attributed verbatim to the Stacks Project.

The existing stage-tower assembly theorem discards its degreewise truncation
identifications, and the existing full-hypercover existence statement does not
retain a prescribed finite skeleton. Reproved stronger, compatible versions in
new modules without changing the existing declarations. These identifications
are necessary for the finite-cochain argument.

`FiniteSplitEtaleHypercover.truncation` is a tuple, not a
`TruncatedFiniteSplitEtaleHypercover`; constructed the latter explicitly.
Also, `finite_each_degree n` describes the nondegenerate constituent, not the
whole simplicial term. The qcqs argument for whole terms uses the finite
truncation's splitting cofan and the existing finite-descent helper, rather than
assuming these are the same object.

The canonical cocone was also checked in Lean for a constant scheme diagram on
a singleton category: all transition and cocone maps reduce to the proved
`relativeSectionMap_id`, and its colimit universal property is proved directly.
The zero-coefficient case is also proved in scratch for every diagram and cone,
without any limit hypothesis: all diagram values and the cocone point are zero,
so `IsColimit.ofIsZero` applies. Both checks use only the three allowed axioms.
These scratch checks are not delivered as unused library modules.
