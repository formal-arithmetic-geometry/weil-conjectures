## What was wrong or changed

The imported auxiliary node was unsplit. Its parent proof had asserted that supported cohomology on the affine-line family was a constant sheaf. That assertion is false in general: for example, with (X=\mathbf A^1_k) and (C=V(t)), supported sections vanish after restricting to (X\setminus C), whereas a nonzero constant sheaf does not. I kept the imported statement, which instead asks for the canonical projection isomorphism on supported cohomology, and split its proof through ordinary affine-line acyclicity plus the localization sequence. The ordinary child is deliberately stated for arbitrary (k)-schemes and both etale and pro-etale finite twists, since the frame application has no finite-type hypothesis on its etale neighborhood.

The existing `lem-pur-a1-direct-image` was checked before creating the child. It assumes a separated finite-type base and only the untwisted constant coefficient object, so it does not duplicate the child. The existing `thm-pur-with-support-exactness` supplies the supported long exact sequence, and `lem-pur-supported-cup-functoriality` supplies arbitrary-morphism pullback, identity/composition, open restriction, boundary compatibility, and the etale/pro-etale comparison; both are in the same unit.
