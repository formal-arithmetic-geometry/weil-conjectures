## What was wrong or incomplete

The old proof used a cohomology-continuity theorem as if its statement already provided the constructible Hom comparison. It does not: the stratum/derived-Hom reduction was missing. The repaired proof uses the existing sheaf-source Hom isomorphism, and explicitly extends it by canonical truncation triangles and the generic Hom-continuity extension theorem. This proves injectivity as well as factorization; the weaker sequential-factorization statement alone would not suffice.

The old lattice argument was invalid. Multiplying transition matrices by a scalar changes the cocycle and can destroy invertibility. Nor does compactness of a scheme imply a pro-etale presentation has finitely many transition matrices. The nodal-curve local system with monodromy multiplication by ell, already described in `sk-lem-stratified-lattice`, has no global lisse lattice. The replacement uses lisse lattices only on finitely many strata, extends them by zero, and reconstructs in the triangulated category by cones.

I removed the assertion that these predicates were identical. For Hom continuity we need only the implication from finite constant models to local finite presentations, which the cited local-model node states verbatim. For essential surjectivity I do not use the existing degree-zero integral-model theorem with the potentially weaker output; the new lattice node supplies genuinely locally finite free integral modules, and extension by zero has genuine finite constant models on its support and the zero model outside. No completion, constant discrete replacement, finite-type scheme restriction, or étale/pro-etale category substitution occurs.
