## Review by NL

I compared the item with de Jong's definition immediately before Lemma 5.7 and the actual two paragraphs of that lemma's proof on printed p.615. His definition requires rational nodes and rational tangent directions; it explicitly identifies the latter with rational points in the normalization. It does not require the irreducible components to be smooth. Thus an irreducible nodal rational curve with a self-node must be included, and a smooth fibre needs no splitting at all. The given normal projective finite-type base is excellent and finite dimensional, but the proof written here only needs its Noetherianity and finite dimension: it never invokes an unrecorded excellence theorem.

For the new branch-cover node I read Stacks `curves.tex`, `remark-quadratic-extension` (0CBT), `remark-trivial-quadratic-extension` (0CBU), `lemma-split-node` (0CBW), and `lemma-etale-local-structure-nodal-family` (0CBY), together with the existing first-Fitting definition and nodal-family statement. The quadratic algebra in 0CBT is the algebra of normalization branches, not an arbitrary quadratic extension. The relative statement is an agent extraction: in etale nodal coordinates uv=h, the singular subscheme is u=v=h=0 and the two tangent directions give its two-sheeted etale cover. Coordinate changes permute these two directions; they therefore give the descent datum for the finite etale double cover. This is a genuine geometric prerequisite left to be proved, not a data definition left unknown. Its fibre identification uses normalization of the curve over the residue field. The cover exists over the singular subscheme, which need not be flat over the base. Properness is imposed only for the additional assertion that the branch scheme is finite over the base. For arbitrary base change, only the branch scheme is pulled back. In particular the node does not make the generally false claim that absolute normalization commutes with arbitrary base change.

For finite residue domination I read Lemma 5.6 on printed p.614 and Situation 5.3 on p.613. Lemma 5.6 prescribes finite separable extensions inside *every* residue field above each selected point. The new node uses the equivalent finite-etale-scheme formulation, by taking a finite separable splitting field of each finite etale residue algebra. It is stronger than selecting just one point above each input point, a distinction essential in step 7. Normalizing the finite output retains finiteness over a finite-type field base, projectivity and its generic field; the split residue algebras stay split after further residue extension. A generically etale Galois alteration has equality of the kernel fixed field with the original function field, since that fixed extension is both separable and purely inseparable. No faithfulness of the original H-action is assumed. All those hypotheses and conclusions are written into this smaller node; it is not the existing arbitrary-alteration domination theorem, which does not assert finiteness over the whole base or prescribed residue splitting.
