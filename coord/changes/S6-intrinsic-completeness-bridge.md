# AlgebraicGeometry.Scheme.AdicCoefficientDatum.towerComplete_iff_intrinsic

## Reason

The existing bridge equated quotient-tower completeness to a universal internal
Koszul representative condition. The public proper-base-change hypothesis instead
uses `PbcIsIntrinsicallyComplete`: an existential generating tuple and representative
in the normalized constant-quotient coefficient presentation. The old theorem cannot
be applied to that hypothesis without the missing presentation and representative
comparison. Its mathematical purpose is precisely this comparison of complete inputs.
State its right-hand side using the existing published intrinsic predicate, preserving
the canonical quotient unit on the left. This retains both directions of the same
mathematical equivalence and requires no constructibility or uniform lower bound.

`CompletedPullback` was unclaimed when adapted. Its original bridge remains an
unproved named theorem, with its source and complete proof plan in the docstring;
this delivery does not count its reformulation as a closed hole. The proof obligation
includes exact coefficient transport, independence of generators and representatives,
and equality of the specified completion units. No arbitrary completion functor is
substituted. `BoundedConstructibleComplete` is a new public import because the bridge's
statement uses its predicate. The import-direction check accepts this import.

Source: current blueprint main-20261015, `sk-prop-pbc-complete`, completed pullback and
complete pro-etale proper base change; the intrinsic-completion definition in
`sec-proetale-coefficients/sk-def-pe-derived-completion`; Stacks 099N, 099M and 091Z.
For I=0 the two units are identities up to the canonical limit comparison. For I=A
the quotient completion is zero, so only zero objects are complete. An empty generator
list is permitted only for I=0. Zero rings and empty schemes give zero module categories.
Thus the repair does not add a hidden nonzero-ideal, nonempty-list or nonempty-scheme
hypothesis.

The only original code occurrence of the theorem name is its declaration. The
`CompletedReductionSquare` docstring mentions it, but applies no direction or binder.
The full downstream inventory below was generated by `tools/downstream.py`;
no existing consumer needs adaptation. The public target statements and all their
used definitions are unchanged, so no target meaning is reopened by a definition edit.
The item additionally introduces proof-local opens and a proof elaboration option;
these are scoped to this module and introduce no public instance or definition.

## Old

```lean
theorem AdicCoefficientDatum.towerComplete_iff_intrinsic (T : Scheme.{t}) (K : d.derived T) : d.TowerComplete T K ↔ ∀ (r : ℕ) (a : Fin r → A) (ha : Ideal.span (Set.range a) = d.ideal), ∀ (C : CochainComplex (reductionModules T (d.completedRing T)) ℤ) (e : DerivedCategory.Q.obj C ≅ K), IsDerivedCompleteIntrinsic T d r a ha K C e
```

## New

```lean
theorem AdicCoefficientDatum.towerComplete_iff_intrinsic (T : Scheme.{t}) (K : d.derived T) : d.TowerComplete T K ↔ PbcIsIntrinsicallyComplete T d K
```
