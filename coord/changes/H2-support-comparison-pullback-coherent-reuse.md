# supportSiteComparisonPullbackCoherent

## Reason

Reuse the already proved `ComparisonPullbackCoherent` interface instead of elaborating a
second copy of the same large equations. The support-prefixed functors and the identity,
composition, chosen-square and coefficient comparison isomorphisms are the same canonical
Kan-extension/adjunction-mate constructions as their unprefixed counterparts. The square
clause of the reused predicate unfolds through `ComparisonSquareComponent` and
`comparisonSquareData` to exactly the original square equation, including `sq.w`.
No hypothesis, universe, quantifier, coefficient category or equation is dropped.

Both direct transfer of the original predicate and a `simpa only` transfer exceeded the
60-second file limit in definitional comparison. Reusing the compact existing predicate
allows the theorem to specialize directly, and the item compiles in about five seconds.
The original baseline with its `sorry` compiles, so this is a conversion-cost repair,
not a claim that the original predicate was mathematically wrong.

The theorem statement text is identical. Its predicate is definitionally identical after
unfolding the canonical maps, so this refactor does not change target meanings. The public
import of `ComparisonPullbackCoherence` is needed by the predicate's body. This interface
change is submitted for independent review together with its complete user inventory.
