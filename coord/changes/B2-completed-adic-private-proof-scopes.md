# CompletedAdicCoefficientDatum private proof scopes

## Reason

The nine proof completions use private generic tensor and resolving-model helpers.
Their scoped notation, local instance/irreducibility attributes, namespace opening and
universe declarations are outside theorem bodies, so the stage-3 static command gate
requests this record. They introduce no public declaration or changed public interface.
Every existing public declaration has the same signature, attributes and definition body.
All added definitions and theorems are private. No target meaning changes and no target
statement review is reopened by these proof-only scopes.

## Old

```lean
universe t
```

There was no `CompletedTensorComparisonProof` namespace or
`FiniteReductionComparison` section and no scoped commands for their private helpers.

universe t uC vC r

namespace CompletedTensorComparisonProof
open SheafOfModules
set_option hygiene false in

  (sheafCompose J (forget₂ CommRingCat.{r} RingCat.{r})).obj R

-- Private, fully proved tensor-comparison helpers.

  [J.WEqualsLocallyBijective AddCommGrpCat.{r}] [HasWeakSheafify J AddCommGrpCat.{r}]
  [J.HasSheafCompose (forget₂ CommRingCat.{r} RingCat.{r})]
  {R₀ B₀ : Sheaf J RingCat.{r}}
-- Private, fully proved restriction/sheafification helpers.

end CompletedTensorComparisonProof

section FiniteReductionComparison
attribute [local irreducible] SheafOfModules.monoidalCategory
-- Private helpers and the completed existing comparison theorem.

The local notation, openings and attributes end with their enclosing scopes.
The new universes occur only in private generic helpers and do not add parameters to any
existing public declaration. Scoped elaboration options are applied with `in` to individual
proof declarations. No existing `variable`, `open`, notation or attribute command changes.
