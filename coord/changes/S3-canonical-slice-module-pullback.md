# RingedSheafSliceAdjunctionData.pullback_eq

## Reason

The representable-slice comparison uses the localization adjunction on the canonical
elementModulePullback functor. The existing default value of the pullback field is
not a constraint, and pullback_formula records only equality of carriers. Add the
functor equality already described in the Q01 interface review and the dependency
node. Preserve the completed ringed_sheaf_slice_adjunction proof and provide rfl
for the additional field in its existing construction. No axiom or sorry is added.
