# InverseImageStalk scoped proof helpers

## Reason

The stage-3 static checker flags added `open`, `variable`, section and option commands
as potential changes to importer-visible behavior. This record documents their scope.
They support fully proved private helpers only. Public statements, definitions used in
statements, original public imports, and all target signatures are unchanged.
No target statement needs a renewed mathematical review.

## Old

The insertion point immediately after `namespace TopCat.Sheaf` had no helper section
or local variable/open/option commands. The two existing public theorem signatures
are unchanged verbatim.

## New

The following added commands introduce the generic private helpers:

```lean
noncomputable section

open CategoryTheory.Limits

section General

set_option backward.isDefEq.respectTransparency false
set_option backward.defeqAttrib.useBackward true

variable (A : Type*) [Category.{u} A]
variable {FA : A → A → Type*} {CA : A → Type u}
variable [∀ P Q, FunLike (FA P Q) (CA P) (CA Q)] [ConcreteCategory.{u} A FA]
variable [HasColimits A] [HasLimits A]
variable [PreservesLimits (CategoryTheory.forget A)]
variable [PreservesFilteredColimits (CategoryTheory.forget A)]
variable [(CategoryTheory.forget A).ReflectsIsomorphisms]
variable {X Y : TopCat.{u}} (f : X ⟶ Y) (x : X)

```

`end General` closes the generic variable scope before either public theorem.
The backward elaboration options are repeated locally for the public proofs.
The surrounding `noncomputable section` is closed before `end TopCat.Sheaf`.
All new declarations are private and fully proved. The `[reassoc]` attribute applies
only to a private helper and creates only a private theorem. The new import of
`Mathlib.Topology.Sheaves.Sheafify` is proof-only, as is the removed import of
`Sheaf.Topology.PresheafModuleStalkFunctor`.
