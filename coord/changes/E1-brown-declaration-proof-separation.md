# Brown-hypotheses declaration and proof-module separation

## Reason

The original arbitrary-field theorem is disputed and still has one named hole. Its two
Paper consumers use only that assertion and its bundle. Proven criteria and conditional
obstructions were unnecessarily imported into both consumers through the same module.
The geometric finite-field specialization and coefficient-isomorphism theorem are the
only textual consumers of the relocated criteria. Move the existing definition and
canonical instance abbreviations to a declaration-only module, and the existing proven
criteria to a separate module which can be imported by a future valid Brown proof without
an import cycle. This is dependency pruning, not a proof of the disputed theorem.

All 36 existing declaration signatures, keywords, visibility and proof/definition terms
are preserved by relocation. The last proof is followed by a different comment; this
accounts for the raw declaration-parser body difference. No new mathematical assertion,
no theorem weakening, no replaced proof by sorry, and no definition change is involved.
The old arbitrary-field theorem stays under its original name in the original module.
No source-library module, target statement, unit route, or DAG proof dependency changes.

```lean
def BrownHypothesesFor
    (Λ : Sheaf (coherentTopology Profinite.{u}) Ab.{u + 1})
    [MonObj Λ] [IsCommMonObj Λ] (X : Scheme.{u}) : Prop :=
  let S := constantModelBoundedConstructible Λ X ⊓ fun K ↦
    DerivedCategory.finiteTorAmplitude _ K
  let L := localizingClosureProEtale Λ X
  LocallySmall.{u + 1} L.FullSubcategory ∧
    ∃ hTri : L.IsTriangulated,
      letI := hTri
      L.IsClosedUnderIsomorphisms ∧
        S.IsTriangulated ∧ S.IsClosedUnderIsomorphisms ∧ S.IsStableUnderRetracts ∧
        ObjectProperty.EssentiallySmall.{u + 1} S ∧
        IsIdempotentComplete L.FullSubcategory ∧
        ∃ hSums : HasCoproducts.{u + 1} L.FullSubcategory,
          letI := hSums
          ∀ (G : Type (u + 1)) [Category.{u + 1} G] (e : G ≌ S.FullSubcategory)
            (hL : ∀ g : G, L (e.functor.obj g).1),
            (∀ g : G, IsCompactObject
              (⟨(e.functor.obj g).1, hL g⟩ : L.FullSubcategory)) ∧
            IsTriangulatedGeneratingFamily
              (fun g : G ↦ (⟨(e.functor.obj g).1, hL g⟩ : L.FullSubcategory))
```

## New

The original module publicly imports the same definitions through:

```lean
public import Sheaf.SixFunctorsBasics.BrownHypothesesDefinitions
```

BrownHypothesesDefinitions retains the original public imports, all six canonical
abbreviations, and the exact bundle definition above. BrownHypothesesCriteria publicly
imports BrownHypothesesDefinitions, retains the original private proof imports, and
contains all the original proven helpers and criteria without mathematical edits.
Neither new module imports the original assertion. There is consequently no cycle,
and the unresolved theorem can later import the criteria if an authorized correction
makes their compactness hypotheses available.

The two adapted consumers each retain their original public import and add exactly:

```lean
import Sheaf.SixFunctorsBasics.BrownHypothesesCriteria
```

Existing criteria nodes are updated only in their Lean module and file attachments.
The original node keeps its theorem attachment. The new definition node attaches the
relocated bundle; it neither restates nor replaces the original theorem.

Two new canonical instance abbreviations in BrownHypothesesCriteria cache repeated
module and derived tensor inference. Their instance attributes are local; their bodies
select existing structures, not new mathematical data. Profiling measured 22.2 seconds
of typeclass inference before this change and 16.8 seconds after it; the file fell from
64.8 seconds to 52.4 seconds. The delivered version has no profiling options.
