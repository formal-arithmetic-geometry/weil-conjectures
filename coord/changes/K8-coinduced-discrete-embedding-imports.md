# Rep.exists_coinduced_discrete_embedding: remove the abelian-category reexport

## Reason

The proof constructs locally constant function modules, right translation, postcomposition,
and the orbit embedding directly. It uses the already proved open-normal-subgroup lemma.
The abelian structure and enough-injectives theorem are not needed. Replace that public
import with the definition of discrete continuous representations and the topology class
used in the unchanged statement. No existing declaration signature or meaning changes.
Private helpers carry all data explicitly; no witness is chosen from an existence theorem.

## Old

```lean
public import Sheaf.CategoryTheory.DiscreteModulesAbelian
public import Mathlib.Topology.LocallyConstant.Algebra
```

## New

```lean
public import WeilConjectures.RepresentationTheory.DiscreteContinuousRep
public import Mathlib.Topology.Connected.TotallyDisconnected
public import Mathlib.Topology.LocallyConstant.Algebra
```
