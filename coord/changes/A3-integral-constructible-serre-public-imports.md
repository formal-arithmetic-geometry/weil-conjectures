# integralConstructible_serre public closure-predicate imports

## Reason

Restore the complete module from `quarantine/Sheaf/Paper/IntegralConstructibleSerre.lean`,
as assigned in `coord/rework.tsv`. The recorded global-build error is:
`Unknown constant CategoryTheory.ObjectProperty.IsClosedUnderKernels`; the diagnostic
explains that the declaration is imported privately. All three closure predicates occur in
the public theorem type. Make their two defining Mathlib modules public imports.
The archived theorem already has a complete proof, so this is a zero-hole interface repair.

## Old

```lean
public import Sheaf.Paper.ContinuousIntegralCoefficients
import Sheaf.Paper.IntegralConstructibleKernels
import Sheaf.Paper.ConstructibleCokernelsExtensions
```

## New

```lean
public import Mathlib.CategoryTheory.ObjectProperty.Kernels
public import Mathlib.CategoryTheory.ObjectProperty.Extensions
public import Sheaf.Paper.ContinuousIntegralCoefficients
import Sheaf.Paper.IntegralConstructibleKernels
import Sheaf.Paper.ConstructibleCokernelsExtensions
```

Every archived declaration, signature, definition and proof is preserved verbatim.
No target statement or definition changes. The DAG attachment and both proof dependencies
are preserved unchanged.
