# PerfectProjectionFormula proof context

## Reason

The signed-totalization proof uses a private categorical transport lemma with independent
object and morphism universes and a private comparison identifying the existing mixed tensor
with its representative API. Local opacity prevents unfolding the chosen mixed isomorphism
while elaborating categorical equations. These commands do not change any public signature,
definition, instance or public import. This record documents the proof context for the
module-command interface check.

## Old

The original item had no `mixed_eq` helper or local mixed-tensor opacity command, and used
only its original universe declaration:

```lean
universe u
```

Its existing private proof import was:

```lean
import Sheaf.Paper.ProEtaleProjectionFormulaArrows
```

## New

The existing universe declaration and all public imports stay verbatim. Before the private
transport lemma the item adds:

```lean
universe v u' v'
```

After the fully proved private comparison it adds:

```lean
attribute [local irreducible] mixed proEtaleMixedTensor
attribute [local irreducible] CategoryTheory.tensorAdjunctionTotal
```

The private proof import reads:

```lean
import all Sheaf.Paper.ProEtaleProjectionFormulaArrows
import Sheaf.Paper.ProEtaleMixedProjectionMate
```

Scoped backward-unification options are used around the totalization proof, matching the
existing proof conventions of the file. The only existing declaration bodies changed are
proofs. The public mixed tensor construction itself is unchanged. The new independent
mixed-mate module contains proved private helpers, one public theorem, and the concrete
`proEtaleProjectionTotal` wrapper around `tensorAdjunctionTotal`, with no holes. The
wrapper fixes the source and target complex types without changing the underlying map.
