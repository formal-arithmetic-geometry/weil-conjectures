# finite_structure_product_compatibility

## Reason
The delivered theorem previously quantified over an arbitrary explicit `μ`, while the DAG and source assert existence of a suitable multiplication map. The old interface is false for arbitrary `μ` (for example `μ := 0` in a nontrivial situation). The corrected existential interface is required by the target and forces the caller adaptation.
