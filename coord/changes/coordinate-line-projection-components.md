# AlgebraicGeometry.ProEtale.CoordinateLine.projection

## Reason

The counit calculation must compare the canonical compact-support projection with its
proper/open components. At the literal standard compactification, elaborating that
conversion repeatedly normalizes the compactification scheme and derived category
instances and exceeds the single-file limit. Expand the canonical map once in its
definition, using the literal chart and projective projection. The new definition is a
term, avoiding the identity wrapper generated by `unfold right` in a tactic definition.
A local reducibility attribute only lets the elaborator see the unchanged target functor.

This is the same specified arrow. In the source library,
`Etale.projectionMapOfCompactification_app_app` expands its middle factor as proper
projection, inverse open projection, and image of the compactification pullback map.
`Etale.leftDerivedUpperStarCompactificationIso_eq` identifies that last map with the
inverse `leftDerivedUpperStarComp` for j,q,p and the standard chart equation. Substituting
these two proved equations in the old definition gives exactly the new five factors,
in the same order, with the same two symmetries. Neither trace nor orientation changes.
No source-library definition is edited. The definition has real data and no new choice.

The statements using this definition retain their mathematical meanings. Since an
implementation used below targets changes, the semantic review is reopened for the
independent reader; this record supplies the component comparison to check.

## New

```lean
@[irreducible]
def projection (K : Etale.DerivedCategoryModule A T) :
    ((Etale.ordinaryFiniteTensor A T).obj K).obj
      ((Etale.affineTraceLineLeft A T).obj (line A N hA T)) ⟶
        (Etale.affineTraceLineLeft A T).obj ((right A N hA T).obj K) :=
  let j := ProjectiveLine.affineChart T
  let q := ProjectiveLine T ↘ T
  let J := Etale.affineTraceOpenLeft A T
  let Q := Etale.ordinaryFinitePushforward A q
  ((Etale.derivedTensorSymmetry (ModuleCat.{u + 1} A) T).hom.app K).app
      (Q.obj (J.obj (line A N hA T))) ≫
    ((Etale.rightDerivedLowerStarProjectionMap (ModuleCat.{u + 1} A) q).app
      (J.obj (line A N hA T))).app K ≫
    Q.map (((Etale.derivedOpenImmersionLowerShriekProjectionIso
      (ModuleCat.{u + 1} A) j).inv.app (line A N hA T)).app
        ((Etale.ordinaryFinitePullback A q).obj K)) ≫
    Q.map (J.map (((Etale.derivedTensor (ModuleCat.{u + 1} A)
      (AffineSpace PUnit.{u + 1} T)).obj (line A N hA T)).map
        ((Etale.leftDerivedUpperStarComp (ModuleCat.{u + 1} A) j q
          (AffineSpace PUnit.{u + 1} T ↘ T)
          (ProjectiveLine.affineChart_over T).symm).inv.app K))) ≫
    (Etale.affineTraceLineLeft A T).map
      (((Etale.derivedTensorSymmetry (ModuleCat.{u + 1} A)
        (AffineSpace PUnit.{u + 1} T)).hom.app (line A N hA T)).app
          ((Etale.ordinaryFinitePullback A (AffineSpace PUnit.{u + 1} T ↘ T)).obj K))
```
