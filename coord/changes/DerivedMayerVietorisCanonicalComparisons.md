# AlgebraicGeometry.schemeDerived_mayerVietoris_directImage

## Reason

The paper uses canonical comparisons. A theorem returning only Nonempty of a functor isomorphism cannot specify its component: proof irrelevance erases the constructed witness, and Classical.choice chooses an arbitrary isomorphism. For example an isomorphism and its negative both inhabit Nonempty, while only the normalized one can satisfy the unit square with fixed adjunctions. The composition dependency already states a determining unit equation; retain its chosen witness. Open restriction is built explicitly by deriving the sectionwise identity, using the construction in the existing dependency. This corrects this held intermediate statement; no Challenge declaration changes. The image
triangle is written through the definitionally equal schemeMVImageTriangle construction
so its right-derived shift structure is elaborated once rather than at each occurrence.
