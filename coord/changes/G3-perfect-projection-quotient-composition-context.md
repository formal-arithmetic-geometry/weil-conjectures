# PerfectProjectionFormula quotient-composition proof context

## Reason

The new private quotient-composition proofs keep the existing chosen module operations
folded. These scoped commands affect proof elaboration only. They introduce no new
public declarations, change no construction, and require no consumer adaptations.
This record documents the module-command change for independent review.

## Old

There was no `QuotientComposition` section or local opacity command at the insertion
point immediately before `section BaseChange`. The item also had the unused private
proof imports `import Sheaf.Paper.RingedProjectionRestriction` and
`import Sheaf.Paper.ProjectionMateExact`. There was no local
`TotalizationProof` section around the existing compatibility theorem.

## New

Unused and unreachable tactic linting are disabled in this file, while normal
elaboration and kernel checking remain enabled:

```lean
set_option linter.unusedTactic false
set_option linter.unreachableTactic false
set_option cleanup.letToHave false
```

Flexible tactic linting is disabled locally on the proved theorem declarations,
using `set_option linter.flexible false in`. The proof-context comment explains
the repeated inspection of large representative tactic contexts. It leaves elaboration and kernel checking enabled.

The let-to-have cleanup preserves local operation abbreviations rather than replacing
them in generated proof terms. This changes proof elaboration only.

A local tactic with a private elaborator constructs the final base-change conversion
by heterogeneous congruence and proof irrelevance, with cached proofs and congruence
theorems. Its recursion decreases an explicit natural-number depth bound. Only this
item's listed aliases can be unfolded. The resulting ordinary equality proof is
checked by the kernel. It does not use native evaluation, admit a goal, skip checking,
or introduce an axiom. Its three imports are private meta imports:

```lean
meta import Mathlib.Lean.Meta.CongrTheorems
meta import Mathlib.Tactic.Set
meta import Mathlib.Util.TermReduce
```

The quotient-composition section contains three proved private helpers and has these
scoped attributes; a fourth private helper is the generic categorical square calculation:

```lean
section QuotientComposition
attribute [local irreducible] proEtaleRingModulePullback proEtaleRingModuleAdjunction
  proEtaleRingCompositeCoefficients proEtaleRingDerivedPullbackFactors
```

The section ends before `section BaseChange`. Before the base-change proof, within
that section, the following existing constructions are also kept folded:

```lean

  proEtaleCanonicalTensorComparison
```

The existing totalization proof also has a local proof section keeping the module
operations folded; its statement and proof argument are unchanged:

```lean

  proEtaleRingModuleAdjunction proEtaleRingDerivedPullbackFactors
```

This section ends immediately after `totalization_compatibility`. Its calls to
`transport_projection` and `tensorAdjunctionTotal_isIso` have explicit category

The base-change theorem separately uses
scoped backward-unification settings. The elaborator
