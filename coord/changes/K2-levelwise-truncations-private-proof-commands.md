# Sheaf.Paper.LevelwiseAdicTruncations private proof command scope

## Reason

Server preflight classifies the added top-level commands as a possible interface
change. They control elaboration only inside this module. This delivery fills
pbc_adic_levelwise_truncations using private helpers; every existing public
signature, definition body, public import and exported instance is preserved.
No consumer adaptation is necessary.

## Old

The existing local registrations are retained verbatim:

```lean
attribute [local instance 2000] reductionRingModulesHasDerivedCategory
attribute [local instance 2000] pbcTowers_hasDerivedCategory
attribute [local irreducible] completedAdicDerivedChange pbcDerivedScalarAdjunction
```

The module already uses declaration-scoped
`set_option backward.isDefEq.respectTransparency false in` commands.
It has no ScalarBounds section or private local EssentiallySmall instance.

## New

The proof adds the following local controls and section:

```lean
private local instance : EssentiallySmall.{u + 1} T.ProEt :=
  essentiallySmallSelf.{0, u, u + 1} _

attribute [local irreducible] pbcComplexCounit pbcExtensionCounit
  pbcDerivedExtensionExistence
attribute [local irreducible] pbcDerivedRestrictComp

section ScalarBounds
attribute [local semireducible] completedAdicDerivedChange
-- private tensor-bound and triangle-comparison helpers
end ScalarBounds
```

The private proof helpers additionally use declaration-scoped
`set_option backward.isDefEq.respectTransparency false in` and
`set_option backward.isDefEq.respectTransparency.types false in`.
The ScalarBounds section restores its temporary transparency setting on exit.
All added instance and attribute registrations are explicitly local; the helpers
are private, proved, and never occur in public signatures or definition data.
The new ordinary imports provide proof-only APIs. Moving the main theorem after
its private helpers preserves its exact public type and visibility.
