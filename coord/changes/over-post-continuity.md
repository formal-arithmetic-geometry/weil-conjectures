# CategoryTheory.overPost_isContinuous

## Reason

The assigned theorem assumes only an arbitrary continuous functor of small Grothendieck
sites. Mathlib's Over.post continuity instances require stronger cover hypotheses. The
existing localized-sheaf module already proves its fibre/unit construction for arbitrary
Grothendieck topologies privately, although its public equivalence theorem specializes to a
precoverage. Expose the proved arbitrary-topology fibre/extension equivalence and add a continuity
corollary using that public API, with no change to any existing declaration. This module is unclaimed. No definition or target meaning changes.

## Old

Neither `CategoryTheory.overPost_isContinuous` nor
`CategoryTheory.exists_localizedSheavesOverRepresentable_general` exists. All existing declarations are retained
verbatim. The private construction and the old public theorem are unchanged.

## New

```lean
theorem overPost_isContinuous {D C : Type u} [SmallCategory D] [SmallCategory C]
    (K : GrothendieckTopology D) (J : GrothendieckTopology C) (f : D ⥤ C)
    [f.IsContinuous K J] (V : D) :
    (Over.post (X := V) f).IsContinuous (K.over V) (J.over (f.obj V))
```

Also added the following fully proved general interface:

```lean
theorem exists_localizedSheavesOverRepresentable_general
    {C : Type u} [SmallCategory C]
    (J : GrothendieckTopology C) [HasWeakSheafify J (Type u)] (U : C) :
    ∃ (P : Sheaf (J.over U) (Type u) ⥤ Over (yoneda.obj U))
      (e : ∀ (H : Sheaf (J.over U) (Type u)) (X : C),
        (P.obj H).left.obj (op X) ≃ Σ a : X ⟶ U, H.obj.obj (op (Over.mk a))),
      (∀ (H : Sheaf (J.over U) (Type u)) (X : C)
        (z : (P.obj H).left.obj (op X)),
        (P.obj H).hom.app (op X) z = (e H X z).1) ∧
      (∀ (H : Sheaf (J.over U) (Type u)) (X Y : C)
        (b : Y ⟶ X) (a : X ⟶ U) (s : H.obj.obj (op (Over.mk a))),
        e H Y ((P.obj H).left.map b.op ((e H X).symm ⟨a, s⟩)) =
          ⟨b ≫ a, H.obj.map (Over.homMk b rfl).op s⟩) ∧
      (∀ (H H' : Sheaf (J.over U) (Type u)) (f : H ⟶ H')
        (X : C) (a : X ⟶ U) (s : H.obj.obj (op (Over.mk a))),
        e H' X ((P.map f).left.app (op X) ((e H X).symm ⟨a, s⟩)) =
          ⟨a, f.hom.app (op (Over.mk a)) s⟩) ∧
      ∃ E : Sheaf (J.over U) (Type u) ≌
          Over ((presheafToSheaf J (Type u)).obj (yoneda.obj U)),
        Nonempty (E.functor ≅ P ⋙ Over.post (presheafToSheaf J (Type u))) ∧
        ∃ r : ∀ (F : Over
            ((presheafToSheaf J (Type u)).obj (yoneda.obj U))) (X : Over U),
            (E.inverse.obj F).obj.obj (op X) ≃
              {s : F.left.obj.obj (op X.left) |
                F.hom.hom.app (op X.left) s =
                  (toSheafify J (yoneda.obj U)).app (op X.left) X.hom},
          (∀ (F : Over
              ((presheafToSheaf J (Type u)).obj (yoneda.obj U)))
            (X Y : Over U) (b : X ⟶ Y) (s : (E.inverse.obj F).obj.obj (op Y)),
            (r F X ((E.inverse.obj F).obj.map b.op s)).val =
              F.left.obj.map b.left.op (r F Y s).val) ∧
          (∀ (F G : Over
              ((presheafToSheaf J (Type u)).obj (yoneda.obj U)))
            (f : F ⟶ G) (X : Over U) (s : (E.inverse.obj F).obj.obj (op X)),

              f.left.hom.app (op X.left) (r F X s).val)
```

Its full statement is also recorded in the existing localized-sheaf node. It replaces the
precoverage binder and its four covering-axiom instances with
`(J : GrothendieckTopology C) [HasWeakSheafify J (Type u)]`; the section formulas and
equivalence conclusion are otherwise identical. It is proved from the existing private
constructions; the original theorem remains unchanged.

Added private pulledFibre and pulledFibre_isSheaf helpers, and a proof-only import of
Mathlib.CategoryTheory.Sites.Continuous. No public import, existing signature, or existing
body changed. Both added theorems have no sorry. The existing node now records the general
interface as its main declaration and retains both declaration names.
