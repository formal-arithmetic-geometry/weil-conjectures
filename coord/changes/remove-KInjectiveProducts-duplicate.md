# CochainComplex.termwise_product_isKInjective_and_isLimit

## Reason

Repair #1428 identifies this bundled theorem as a duplicate of
`CochainComplex.isKInjective_of_isLimitFan` and
`DerivedCategory.isLimitFanMkQObjOfIsKInjective`. Remove the duplicate and
re-point all three declaration callers to the existing APIs available here.
The exact reviewed upstream pair and its Products source are absent from both
this snapshot and the installed source checkout. We do not invent their signatures,
import a missing module, or redeclare them. The local replacements use
`HomotopyCategory.isLimitFanQuotient`, right-orthogonal closure under limits,
`CochainComplex.isKInjective_iff_rightOrthogonal`, and
`CochainComplex.IsKInjective.Qh_map_bijective` instead.

## Old

```lean
theorem termwise_product_isKInjective_and_isLimit
    {C : Type u} [Category.{v} C] [Abelian C] [HasDerivedCategory.{w} C]
    {T : Type t} (I : T → CochainComplex C ℤ) [∀ s : T, (I s).IsKInjective]
    [∀ n : ℤ, HasLimit (Discrete.functor I ⋙ HomologicalComplex.eval C (ComplexShape.up ℤ) n)] :
    let P := HomologicalComplex.coneOfHasLimitEval (Discrete.functor I)
    IsKInjective P.pt ∧ Nonempty (IsLimit (DerivedCategory.Q.mapCone P))
```

The module also has private `productHomotopy` and `mapProduct` definitions.

## New

Remove the duplicate theorem and both private helpers. Keep the compatibility
module with exactly its three original public imports; remove its private
DerivedCategory.KInjective import. No theorem or alias replaces the retired name.
The node has no verified Lean attachment after retirement; the upstream pair remains an unverified citation in this record and the report.
The mathematical node statement is unchanged.

In each caller only the removed theorem application, its required import, and
prose references to that application are changed. The right-derived-functor
caller already publicly imports the source Products module, so it needs no new
private import. The replacements prove K-injectivity using the existing product
cone in the homotopy category and right-orthogonal closure. They pull back an
arbitrary derived cone by essential surjectivity, lift its legs using the
K-injective Hom bijections, and prove uniqueness using their injectivity.
`quotientCompQhIso` gives exactly the original localized cone. No resolution
hypothesis, exactness hypothesis, or universe is added. Every existing caller
signature and visibility stays identical. No definition or target meaning changes.
All three callers already have countable products in their coefficient category,
so the available `isLimitFanQuotient` hypothesis is satisfied without changing
any statement. The retired theorem's node retains its arbitrary degreewise-family product
statement, with no verified Lean attachment; the upstream pair is only an
unverified citation.
