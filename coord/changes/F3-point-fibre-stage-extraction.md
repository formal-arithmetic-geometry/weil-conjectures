# WeilConjectures finite-stage point-fibre declarations

## Reason

The remaining common-stage functor proof needs one smaller theorem: its displayed
arrow is invariant under one further coefficient extension. Stating that theorem in
its own module requires the already constructed finite-stage fibres and representative
formula in a dependency module. Otherwise that module and the item import each other.
Move the finite-stage constructions to `Sheaf.Paper.FiniteCoefficientPointStages`
and publicly reexport them from the original module. This is an extraction to make
the mathematical dependency acyclic, undertaken before any compile timeout; it is
not a split to evade the per-file limit.

A source comparison checked all 53 existing public signatures and all
non-theorem bodies: they are retained verbatim. Exactly 51 public declarations
move into the new dependency module. The only edits in the extracted source are its module heading
and the representative's blueprint tag. The original public imports remain on the
item. No target statement or mathematical definition changes. No consumer needs an
adaptation. The representative-transport theorem is a genuine equality about one
extension, with no descended functor in its hypotheses or conclusion. No existing
consumer uses a relocated private helper or imports all private declarations
from the original item.

## Old

The declarations preceding `pointQbarFibre_existsUnique` lived in
`lean/Sheaf/Paper/FiniteCoefficientPoint.lean`, with the representative defined as:

```lean
noncomputable def pointQbarFibreRepresentative
    (A B : generalAlgebraicallyClosedConstructibleCategory l Ω (Spec (.of D.k)))
    (F : Padic.FiniteCoefficientFields l Ω) (hA : A.stage ≤ F) (hB : B.stage ≤ F)
    (f : A.toStage hA ⟶ B.toStage hB) :
    pointQbarFibreObj D l hl Ω A ⟶ pointQbarFibreObj D l hl Ω B :=
  (DerivedCategory.pointFdQbarStageComp l Ω hA).inv.app
      ((pointStageFibre D l hl Ω A.stage).obj A.obj) ≫
    (DerivedCategory.pointFdQbarStage l Ω F).map
      ((pointStageFibreScalarIso D l hl Ω A.stage F hA).inv.app A.obj ≫
        (pointStageFibre D l hl Ω F).map f ≫
          (pointStageFibreScalarIso D l hl Ω B.stage F hB).hom.app B.obj) ≫
    (DerivedCategory.pointFdQbarStageComp l Ω hB).hom.app
      ((pointStageFibre D l hl Ω B.stage).obj B.obj)
```

The full moved declaration inventory is recorded in the new node
`def-weil-point-fibre-stage-constructions`; the unchanged source is the old file's
prefix through this definition. The original item theorem was left `:= by sorry`.

## New

The identical representative definition above, together with the unchanged prefix,
now lives in `lean/Sheaf/Paper/FiniteCoefficientPointStages.lean`. The original
module retains its existing public imports and adds:

```lean
public import Sheaf.Paper.FiniteCoefficientPointStages

import Sheaf.Paper.PointFibreRepresentativeTransport
```

`WeilConjectures.pointQbarFibre_existsUnique` keeps its exact signature and now has
a complete quotient-descent proof, using the new one-step transport theorem. The
body of `WeilConjectures.pointQbarFibre` is unchanged. One lower theorem remains
unproved, `WeilConjectures.pointQbarFibreRepresentative_transport` in its own module.
The extraction adds no choice of data and no mathematical assumption.
