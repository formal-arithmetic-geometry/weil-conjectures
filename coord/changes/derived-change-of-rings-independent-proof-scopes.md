# SheafOfModules.derivedChangeOfRingsIndependentCoefficients

## Reason

Complete the original independent-universe theorem, including its K-flat invariance argument.
The static preflight conservatively classifies added scope commands as an interface change.
This record documents those commands and every downstream module for independent review.
The public theorem signature, underlying-ring abbreviation and public imports stay verbatim.
The proof-only imports change and all new declarations are private, fully proved helpers.
No module is adapted and no target statement or mathematical definition changes.
The private comparison is constructed at the level of underlying abelian sheaves using
Mathlib's natural sheafification and scalar-restriction isomorphisms; exact forgetting
then detects acyclicity. This avoids the expensive module-valued adjunction reduction.

The additional `open MonoidalCategory` resolves names inside this file. The notation and
section variables are local to `IndependentTensor` and `TensorAcyclicity`. Every added instance
attribute is explicitly `local`; the local irreducibility attribute prevents expensive
unfolding of the sheaf monoidal localization while elaborating the helper proofs. Both
sections end before the existing public theorem. Single-declaration `set_option ... in`
commands also have local scope. None supplies a global instance or attribute to importers.
