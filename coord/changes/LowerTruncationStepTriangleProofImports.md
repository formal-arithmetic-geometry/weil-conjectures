# LowerTruncationStepTriangle proof imports

## Reason

The HomologySequence import serves only the proof, so it must not be public.
The new proof-only upstream TStructure import already imports HomologySequence
and FullyFaithful. Remove the redundant explicit import. Existing declarations,
their signatures, and all definitions remain unchanged. The three direct users
import this module privately and already import the relevant t-structure or
homology-sequence APIs themselves. No adaptation is required.

```lean
public import Mathlib.Algebra.Homology.DerivedCategory.HomologySequence

```
