# ScalarExtensionFunctor diagnostic option

## Reason

Repair return 953e9793f: the source census reads the option-name component in
`set_option warn.sorry false` as an unattributed hole. Remove the unnecessary
file-local diagnostic option. The compile driver already controls diagnostics.
This changes no declaration, type, definition body, visibility, instance or notation.
The static interface checker nevertheless requests a change record for this command.
Lean does not export this diagnostic option to importing modules.

The retained proofs also add `open scoped ZeroObject` for source elaboration. The identity
proof uses a single-declaration `open scoped ChangeOfRings in`. These select existing scoped
syntax and instances; they declare no notation or instances. Added proof-only imports and
proved private helpers support the closed theorems. Every existing public declaration,
including every definition body and every target signature, is unchanged.

```lean
set_option autoImplicit false
set_option warn.sorry false
set_option backward.isDefEq.respectTransparency false
```

## New

```lean
set_option autoImplicit false
set_option backward.isDefEq.respectTransparency false
```
