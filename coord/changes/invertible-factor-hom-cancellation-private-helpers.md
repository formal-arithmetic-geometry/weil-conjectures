# CategoryTheory.MonoidalClosed.invertibleFactorHomCancellation

## Reason

The delivery adds two `omit [SymmetricCategory C] in` commands scoped to private
proved helpers, `tensorTo_natural` and `tensorTo_factor`. Their identities require
only the monoidal closed structure. The stage-3 static command comparison treats
these commands as an interface change and requests this record. They affect only
the immediately following private theorem, not any public declaration or later
section context. Neither helper occurs in a public signature or definition body.
No public signature or definition changes; no target statement review is reopened.

## Old

No scoped commands or private helpers between `ihomTensorBoth` and the main theorem.
The public `ihomTensorBoth` definition and the complete public
`invertibleFactorHomCancellation` signature remain verbatim identical.

## New

The following command precedes each of the new private proved helpers
`tensorTo_natural` and `tensorTo_factor`:

```lean
omit [SymmetricCategory C] in
```

It removes the unused section assumption only from that helper. The main theorem
keeps all original assumptions. The redundant proof-only import
`Mathlib.CategoryTheory.Equivalence` is removed; it is already supplied by the
unchanged public import of the rigid-category library module. No exported import,
instance, notation, or attribute changes.
