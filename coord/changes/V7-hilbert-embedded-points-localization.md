# AlgebraicGeometry.Scheme.Modules.existsUnique_coherent_submodule_of_affine_cover

## Reason

The previous Lean signature does not state the DAG's localization theorem. Its `Nloc`
is an arbitrary family, with no localization, restriction, or sheaf condition. Even on
a single affine chart U = X = Spec(k × k) for a field k, set N = 0, Nloc X = 0
and Nloc V = all sections on one nonempty component V, with F = O_X. The
compatibility hypothesis is tautological for a singleton cover. A subobject with zero image on X and nonzero full image on V cannot be the
asserted coherent (hence quasi-coherent) subsheaf. Moreover the old conclusion requires
all Nloc i V on opens V outside U_i, where the hypotheses give no compatibility.
STATEMENT-DISPUTED (old signature): arbitrary Nloc need not be a subsheaf or a localization.

The DAG's mathematical statement is correct and stays unchanged. Replace the invalid
Lean encoding by the explicitly constructed affine subsheaf generated by N_i, taking
the abelian image of the finite free map defined by a finite spanning set. The helper
proves this is mono and quasi-coherent and has precisely N_i as its affine section
image. On principal opens it is the usual localized submodule: apply affine
quasi-coherent sections/localization to the finite free map and its image. Thus
compatibility on common principal opens has exactly the meaning in the DAG, without
an arbitrary extra family. The conclusion is stronger than the source's principal-open
clause in giving the constructed range on every open contained in each chart.

The construction uses a finite generating set chosen from the fully proved Mathlib
finite-generation characterization. It chooses no data from an unproved existence theorem.
No target signature or adopted source module is changed.

## New

```lean
theorem existsUnique_coherent_submodule_of_affine_cover
    (X : Scheme.{u}) [IsLocallyNoetherian X] (F : X.Modules)
    (hF : RingedSpace.IsCoherent X.toRingedSpace F)
    (I : Type u) (U : I → X.Opens) (hU : ∀ i, IsAffineOpen (U i))
    (hcover : ∀ x : X, ∃ i, x ∈ U i)
    (N : ∀ i, Submodule Γ(X, U i) Γ(F, U i))
    (hN : ∀ i, Module.Finite Γ(X, U i) (N i))
    (hcompat : ∀ (i j : I) (W : X.Opens) (hi : W ≤ U i) (hj : W ≤ U j),
      (∃ (f : Γ(X, U i)) (g : Γ(X, U j)),
        W = X.basicOpen f ∧ W = X.basicOpen g) →
      Set.range ((affineSectionSubmodule X F (U i) (N i) (hN i)).2.val.app
        (op (Over.mk (homOfLE hi)))) =
      Set.range ((affineSectionSubmodule X F (U j) (N j) (hN j)).2.val.app
        (op (Over.mk (homOfLE hj))))) :
    ∃! K : Subobject F,
      RingedSpace.IsCoherent X.toRingedSpace (K : X.Modules) ∧
      (∀ (i : I) (W : X.Opens) (hi : W ≤ U i),
        Set.range (K.arrow.app W) =
          Set.range ((affineSectionSubmodule X F (U i) (N i) (hN i)).2.val.app
            (op (Over.mk (homOfLE hi))))) ∧
      (∀ i, LinearMap.range (K.arrow.val.app (op (U i))).hom = N i) ∧
      (∀ i, Nonempty (Γ((cokernel K.arrow : X.Modules), U i) ≃ₗ[Γ(X, U i)]
        (Γ(F, U i) ⧸ N i)))
```
