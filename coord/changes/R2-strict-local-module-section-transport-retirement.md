public declarations and preserve that consumer's public signature exactly.

The sole direct consumer uses a new, fully proved
ModuleSectionsIsoTransport theorem. This theorem works for arbitrary schemes A,B,X,
an isomorphism σ:A≅B and maps g,h with σ≫h=g. It constructs an equivalence from
module global sections to set terminal sections and proves its formula for every
object U and every v:B→U over X. The consumer specializes it to pullback symmetry
for its unchanged small-model structural map. Its public declaration, all hypotheses,
and the given linear-map representative formula remain byte-for-byte unchanged.

The generic theorem is a proof-level compatibility tool. It neither defines a second
strict-local equivalence nor assumes that the full and small spectra are equal.
It proves the entire naturality calculation from the existing coefficient, composition,
and restriction comparisons; it does not add a hole. No source-library file or target
statement is changed. No public data definition surviving the retirement is changed,
so definitions in the targets retain their meanings.
