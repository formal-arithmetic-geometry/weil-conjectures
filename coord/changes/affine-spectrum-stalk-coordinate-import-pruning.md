# Sheaf.AlgebraicGeometry.AffineSpectrumStalkCoordinateData import pruning

## Reason

The proof uses the linear tensor-pullback stalk isomorphism and the extension/restriction
adjunction. It does not use the additive cohomology comparisons of
`IsoPullbackStalkCohomology`. Replace that public import with the lower module that defines
all objects of the existing statement. The auxiliary stalk-additivity instance from
`StalkComparisonSourceTransport` is needed only in the proof, so import it privately.
The static checker also notices the three declaration-local `omit ... in` commands and
the declaration-local unused-variable linter option. These commands affect only private
helpers or diagnostic output and do not alter any exported instance or theorem type.
No existing signature, definition, visibility or target meaning changes.
