# ExceptionalIntegralScalar.ReductionMates.evaluation_normalized

## Reason

Finite scalar extension is realized using `pbcDerivedExtend`, whereas reconstruction
finite evaluation uses `coefficientFiniteDerivedExtension`, hence the recorded
`scalarReductionDerivedExtension`. The library provides the canonical
`PurCompactSupport.finiteReductionIso` between these derived tensors. The old field
omitted this comparison and used heterogeneous equality between the bare arrows.
The corrected field states the actual normalized diagram as a homogeneous equality,
including the reconstruction equalities and the canonical quotient-tensor comparison.
This is the tensor-unit normalized comparison already used by
`PurCompactSupport.IsRecordedIdentification`; it adds no geometric hypothesis.

To expose a strictly smaller remaining left-square obligation without an import cycle,
the original public data is relocated verbatim to
`Sheaf.Paper.ExceptionalIntegralScalarMatesData` and reexported from the item. The only
existing data change is the finite normalization field below. The new
`Reconstruction.evaluationRealization` composes the existing reconstruction equalities
and the reduction evaluation isomorphism. No source-library module is edited.

## Old

```lean
evaluation_normalized (side : Bool)
      (K : C.{u} l Ω (endpoint X Y side) (.integral E)) :
    HEq ((finiteTorConstructible l E.carrier (n + 1) (Nat.succ_pos n)
      (endpoint X Y side)).ι.map ((evaluation side).inv.app K))
      (((tr.reconstruction E side).calculus.reductionEvaluation n).hom.app K.obj)
```

All public data declarations were directly in
`Sheaf.Paper.ExceptionalIntegralScalarMates`.

## New

```lean
evaluation_normalized (side : Bool)
      (K : C.{u} l Ω (endpoint X Y side) (.integral E)) :
    (finiteTorConstructible l E.carrier (n + 1) (Nat.succ_pos n)
      (endpoint X Y side)).ι.map ((evaluation side).inv.app K) =
      ((tr.reconstruction E side).evaluationRealization l E (endpoint X Y side) n).hom.app K ≫
        (PurCompactSupport.finiteReductionIso l E.carrier (endpoint X Y side) n).inv.app K.obj ≫
        (eqToIso (d.finiteScalar_eq (s := .integral E) E ⟨n + 1, Nat.succ_pos n⟩
          (PurCompactSupport.reduction l E.carrier (n + 1) (Nat.succ_pos n))
          (Allowed.reduction E ⟨n + 1, Nat.succ_pos n⟩) side)).inv.app K
```

The same data names are declared in `Sheaf.Paper.ExceptionalIntegralScalarMatesData`;
the item publicly imports this module, which retains every original public prerequisite.
The evaluation isomorphism is actually constructed by full-inclusion lifting in
`Sheaf.Paper.ExceptionalIntegralReductionEvaluation`, and its normalization is proved.
The right mate equation is proved from the left equation and the transported counit,
using the injective adjunction Hom equivalence. Only the geometric left-square equation
is split off as `integralReductionLeftCompatibility`.
