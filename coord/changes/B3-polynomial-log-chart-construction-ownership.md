# PolynomialLogChart construction ownership

## Reason

The polynomial chart calculation must be usable before the log-regularity theorem.
Move its seven existing definitions into a definition module, publicly imported by
`Sheaf.AlgebraicGeometry.PolynomialLogChartRegularity`. Their names, signatures,
visibility and bodies stay identical. Only the owning module and blueprint tags
change. No target meaning changes, and no arbitrary object is chosen from a theorem.
The item node gains the definition node as a statement dependency and its Lean
attachment lists the theorem; the new definition node owns the relocated declarations.

## Old

The following block was declared in
`lean/Sheaf/AlgebraicGeometry/PolynomialLogChartRegularity.lean`:

```lean
namespace PolynomialLogChart

/-- The polynomial structural map `(p,n) ↦ α(p) ∏ tᵢ^nᵢ`.
Source: ILO VI 1.8, polynomial chart case
(blueprint: lem-trf-polynomial-log-chart-regularity). -/
noncomputable def structuralMap {C P : Type u} [CommRing C] [CommMonoid P]
    (α : P →* C) (r : ℕ) : P × Multiplicative (Fin r →₀ ℕ) →* MvPolynomial (Fin r) C :=
  ((MvPolynomial.C : C →+* MvPolynomial (Fin r) C).toMonoidHom.comp α).coprod
    (MvPolynomial.monomialOneHom C (Fin r))

/-- The canonical global-section germ in the recorded strict henselization.
Source: ILO VI 1.2, strict localization
(blueprint: lem-trf-polynomial-log-chart-regularity). -/
noncomputable def ringGerm {X : Scheme.{u}} {Ω : Type u} [Field Ω] [IsAlgClosed Ω]
    (x : Spec (.of Ω) ⟶ X) : Γ(X, ⊤) →+* Scheme.strictHenselizationRing x :=
  (Scheme.ΓSpecIso (Scheme.strictHenselizationRing x)).hom.hom.comp
    (Scheme.strictHenselizationStructuralMap x).appTop.hom

/-- The ideal of log nonunits in the affine-neighbourhood strict henselization.
Source: ILO VI 1.2; transport of `EtaleLogStructure.nonunitIdeal`
(blueprint: lem-trf-polynomial-log-chart-regularity). -/
noncomputable def nonunitIdeal {X : Scheme.{u}} (M : EtaleLogStructure X)
    {Ω : Type u} [Field Ω] [IsAlgClosed Ω] (x : Spec (.of Ω) ⟶ X) :
    Ideal (Scheme.strictHenselizationRing x) :=
  Ideal.map (strictLocalRingStrictHenselizationIso X x).hom.hom (M.nonunitIdeal x)

/-- The characteristic image of a section of a global chart.
Source: ILO VI 1.1--1.2
(blueprint: lem-trf-polynomial-log-chart-regularity). -/
noncomputable def characteristicChart {X : Scheme.{u}} (M : EtaleLogStructure X)
    {P : Type u} [CommMonoid P]
    (c : P →* M.monoidSheaf.obj.obj (op (Scheme.Etale.mk (𝟙 X))))
    {Ω : Type u} [Field Ω] [IsAlgClosed Ω] (x : Spec (.of Ω) ⟶ X) :
    P →* M.characteristic x :=
  Associates.mkMonoidHom.comp
    ((M.toEtalePrelogStructure.germ x (Scheme.Etale.mk (𝟙 X)) (Over.homMk x)).hom.comp c)

/-- A polynomial coordinate as an element of the strict local ring.
Source: ILO VI 1.8, polynomial chart case
(blueprint: lem-trf-polynomial-log-chart-regularity). -/
noncomputable def coordinate {C : Type u} [CommRing C] {r : ℕ}
    {Ω : Type u} [Field Ω] [IsAlgClosed Ω]
    (w : Spec (.of Ω) ⟶ Spec (.of (MvPolynomial (Fin r) C))) (i : Fin r) :
    Scheme.strictHenselizationRing w :=
  ringGerm w ((Scheme.ΓSpecIso (.of (MvPolynomial (Fin r) C))).inv (MvPolynomial.X i))

open Classical in
/-- Exactly the coordinates in the maximal ideal; the finite set may be empty.
Source: ILO VI 1.8, polynomial chart case
(blueprint: lem-trf-polynomial-log-chart-regularity). -/
noncomputable def vanishingCoordinates {C : Type u} [CommRing C] {r : ℕ}
    {Ω : Type u} [Field Ω] [IsAlgClosed Ω]
    (w : Spec (.of Ω) ⟶ Spec (.of (MvPolynomial (Fin r) C))) : Finset (Fin r) :=
  Finset.univ.filter (fun i ↦ coordinate w i ∈
    IsLocalRing.maximalIdeal (Scheme.strictHenselizationRing w))

/-- The ideal generated by precisely the vanishing coordinates.
Source: ILO VI 1.8, polynomial chart case
(blueprint: lem-trf-polynomial-log-chart-regularity). -/
noncomputable def coordinateIdeal {C : Type u} [CommRing C] {r : ℕ}
    {Ω : Type u} [Field Ω] [IsAlgClosed Ω]
    (w : Spec (.of Ω) ⟶ Spec (.of (MvPolynomial (Fin r) C))) :
    Ideal (Scheme.strictHenselizationRing w) :=
  Ideal.span (Set.range (fun i : vanishingCoordinates w ↦ coordinate w i.1))

end PolynomialLogChart
```
