## Reason
The parent ordinary scalar tower theorem is now assembled from separately named component propositions so the three independent coherence equalities can be proved in parallel.

## Old
A single theorem `scalarOperationsOrdinary_tower` stated the conjunction of pullback, tensor, and internal-Hom equalities, with one proof hole.

## New
Three proposition definitions and three component theorems expose the same three clauses. The parent theorem's public statement is unchanged and its proof is the conjunction constructor applied to those component theorems.

## Users
The existing users of `scalarOperationsOrdinary_tower` continue to use the unchanged conjunction. The new component names are available to future proofs in the same module import closure.
