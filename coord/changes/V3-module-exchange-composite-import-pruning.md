# AlgebraicGeometry.Etale.moduleExchange_composite_baseChange

## Reason

Prune two unused public imports after proving the complete pasting theorem. The
module-valued inverse-image functors already have their required exactness instances
through ExactUnboundedExchange. BaseChangeMapAbelianAndSets is not needed for either
the theorem, the composition isomorphism, or the proof. No declaration signature,
visibility, or definition changes. The new private proof helpers use the generic
module-valued functors directly.

## Old

```lean
public import WeilConjectures.AlgebraicGeometry.EtaleInverseImageModulesExact
public import Sheaf.AlgebraicGeometry.BaseChangeMapAbelianAndSets
```

## New

These two import lines are removed. All three other original public imports remain.
A proof-only import of
WeilConjectures.CategoryTheory.DerivedCategory.MapDerivedCategoryMate supplies the
proved coherence API used to derive the associativity equation.
