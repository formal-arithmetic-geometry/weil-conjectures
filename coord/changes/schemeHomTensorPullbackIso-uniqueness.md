# schemeHomTensorPullbackIso

## Reason

Partial repair of the tensor choice-data audit. The existing proved
IsCanonicalPullbackTensorComparison.unique fixes the hom components for the shared
counit. Reconstruct the iso componentwise with those same hom components; Iso.ext
identifies the result with the old chosen iso, including its inverse. No new theorem
is needed. The separate normalization of schemeHomPullbackAdjunction stays open.

## Old

```lean
def schemeHomTensorPullbackIso {X Y : Scheme.{u}} (f : X ⟶ Y) :
    tensor (schemeDerivedCategory Y) ⋙ derivedPullback f ≅
      (derivedPullback f).prod (derivedPullback f) ⋙ tensor (schemeDerivedCategory X) :=
  Classical.choose (exists_schemeHomTensorPullbackIso f)
```

## New

```lean
def schemeHomTensorPullbackIso {X Y : Scheme.{u}} (f : X ⟶ Y) :
    tensor (schemeDerivedCategory Y) ⋙ derivedPullback f ≅
      (derivedPullback f).prod (derivedPullback f) ⋙ tensor (schemeDerivedCategory X) :=
  let t := Classical.choose (exists_schemeHomTensorPullbackIso f)
  NatIso.ofComponents (fun Z ↦ asIso (t.hom.app Z)) (fun a ↦ t.hom.naturality a)

```

The second reading demotes the upstream ExactFunctor import to a plain import,
retaining its needed local instance infrastructure. The
Mathlib mapDerivedCategory interface remains publicly available via GlobalDerivedHom.
Respecting transparency in the choice wrapper changes elaboration only. The
existence proof now uses canonicalPullbackTensor_monoidal_realization to identify
each component with an inverse tensorator. The unused private helpers pullbackTensorModelMap_isIso and pullbackCounit_isIso
and three K-flat proof imports are removed; all existing public signatures are unchanged.

Local irreducibility attributes on the two
comparison wrappers keep the final proofs from expanding their construction data;
these attributes are confined to this module and do not affect importers.
