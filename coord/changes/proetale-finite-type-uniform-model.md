# AlgebraicGeometry.Scheme.etale_cover_of_proetale_uniform_finiteType_model

## Reason

Changed modules: `Sheaf.AlgebraicGeometry.ProEtaleFiniteLocalSystemsTwist` and
`Sheaf.Paper.ProEtaleUniformModelEtaleCover`.

The assigned twist needs arbitrary discrete rings and finitely presented models. The existing
uniform-model proof used finite underlying sets only to take finite intersections of covering
sieves. A finite generating set suffices: linear equality on generators gives equality, and
containing their images in the constant-unit image submodule contains the image of every element.
This strictly generalizes a proved argument and introduces no proof hole. The auxiliary module
was unclaimed when changed. Existing public signatures, public imports, and definitions stay
identical. Only private helper hypotheses are generalized, and one public theorem is added.
No target-used definition changes, so no target statement review is reopened.

## New

```lean

      Presieve.ofArrows W g ∈ proetalePrecoverage X ∧
        ∀ i, Nonempty ((AlgebraicGeometry.ProEtale.upperStar
          (ModuleCat.{u + 1} Λ) (g i)).obj F ≅
            (constantSheaf (ProEt.topology (W i)) (ModuleCat.{u + 1} Λ)).obj M)) :
    ∃ 𝒰 : Cover.{u} etalePrecoverage X, ∀ i : 𝒰.I₀,
      Nonempty ((AlgebraicGeometry.ProEtale.upperStar
```

The private helpers instead require Module.Finite Λ M and Module.Finite Λ N.
The proof takes the finite set from Module.Finite.fg_top, detects linear maps with
LinearMap.ext_on, and proves the image containment with Submodule.span_le. All other
sheaf constructions and comparison steps are unchanged. The item itself adds only proved
helpers and proofs, with its four predicate definitions and original theorem signature identical.
The original direct consumer was compiled successfully without edits.

The item retains the original `open CategoryTheory CategoryTheory.Limits Opposite` and
`open AlgebraicGeometry`, and adds `open Scheme` for proved helper calculations. It adds
local transparency options and a local instance attribute for the proved `ProEt.sliceDense`;
these change proof elaboration only. No global instance is introduced. The old and new
predicate definitions are textually identical; the original theorem signature is identical.
