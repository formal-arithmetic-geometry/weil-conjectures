# AlgebraicGeometry.perfect_derivedDirectImage_baseChange retirement

## Reason

Retire the Sheaf implementation as requested by coord/repairs.txt, publicly re-exporting
WeilConjectures.AlgebraicGeometry.Cohomology.DirectImage.PerfectBaseChange. The source theorem
has an affine Cech-complex interface, not the stronger arbitrary-base derived-category interface
of the removed theorem. It cannot be substituted by renaming. All actual users are adapted in
this delivery to already-stated theorems supplying precisely their required conclusions.
Perfectness uses properFlat_single_derivedDirectImage_perfect. Three fibre comparisons use
exists_isIso_canonicalModuleBaseChange_of_isFlatOver. The rank-matching caller keeps the
prescribed comparison and proves invertibility by the affine canonical comparison/locality
lemmas and schemeDerived_isIso_of_openRestriction. No caller statement or public definition
changes. No arbitrary witness is chosen to define data.

```lean
    (G : X.Modules) [SheafOfModules.IsFinitePresentation (R := X.ringCatSheaf) G]
    (hG : G.IsFlatOver f) :
    Scheme.IsPerfect S ((schemeDerivedDirectImage f).obj
      ((DerivedCategory.singleFunctor
        (SheafOfModules.{uPF} (moduleRings X.toRingedSpace)) 0).obj G)) ∧
      ∀ {T : Scheme.{uPF}} (g : T ⟶ S) φ, IsDerivedModuleBaseChangeMap f g G φ → IsIso φ
```

Four private helper theorems were also declared in the item:
`hasDerivedCategory_of_equivalence`, `isFinitePresentation_of_isZero`, `unit_isPerfect`, and
`isIso_of_open_restrictions`. The first two had an `import all` user,
ProperFlatImageGlobalHomBaseChangeIso. That user now imports the existing corresponding
private helpers from ProperFlatSingleDerivedDirectImagePerfect and
ProperFlatDerivedDirectImagePerfect. Their same mathematical constructions are already in
those modules; nothing is restated or newly assumed.

## New

The item declares no theorem or definition. Its existing three public imports remain verbatim,
and the public source import
`WeilConjectures.AlgebraicGeometry.Cohomology.DirectImage.PerfectBaseChange` is added.
The eight public theorem callers and the private-helper importer are adapted atomically.
Every declaration in those nine modules retains its existing signature and visibility.
