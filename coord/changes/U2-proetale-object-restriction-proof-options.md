## Reason

The static preflight flags the declaration-scoped transparency options attached to
new private helpers as a command-level interface change. This record documents their
scope. Each `set_option ... in` applies only to its following private declaration.
They let elaboration identify the existing sheaf, coefficient and module constructions.
They introduce no global option, instance, notation or public declaration. All four
original public imports and every existing declaration signature, attribute and
visibility are identical. Public definitions retain their original bodies. Only the
existing theorem proof changes, and its new helpers are private and fully proved.

helpers. The theorem ended with:
