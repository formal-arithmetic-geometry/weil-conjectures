# Proof-local elaboration commands in IntegralLfpConstantModelComparison

## Reason

The completed proof uses local instances for the canonical continuous condensed ring,
a notation scope, and a transparency elaboration option. The conservative interface
checker treats changes to these top-level commands as an interface change. This record
makes that change explicit. The option affects elaboration in this file only; the scope
and the `local instance` attributes are also local to this file. No existing public
signature, coefficient definition, global instance or target statement changes.
The two new point-pullback instances are declared `private` and prove colimit preservation
and additivity from the existing adjunction. The independent reader checks their instance
registration as requested by preflight; no existing instance is changed.

## Old

The original module had the following command block, verbatim:

```lean
set_option autoImplicit false

universe u

open CategoryTheory MonoidalCategory MonObj
```

It had no local continuous-ring instance attributes and no declaration-scoped
transparency override for `finiteConstantModel_of_iso`.

## New

The completed module has the following command block, verbatim:

```lean
set_option autoImplicit false
set_option backward.isDefEq.respectTransparency.types false


universe u

open CategoryTheory MonoidalCategory MonObj
open scoped CategoryTheory.Obj
```

Before the new generic continuous-coefficient proof:

```lean
attribute [local instance] Profinite.continuousMapRingObjOfUniverseMonObj
attribute [local instance] Profinite.isCommMonObj_continuousMapRingObjOfUniverse
```

The new private helper `finiteConstantModel_of_iso` is checked with:

```lean
set_option backward.isDefEq.respectTransparency.types true in
```

All original public declarations retain their signatures and visibility. In particular,
`integralCondensedRing`, `integralCoefficientRing`, its monoid/commutativity instances,
and `integralLfpConstantModelComparison` retain the same types; the coefficient definition
bodies are unchanged. No downstream source adaptation is needed.
