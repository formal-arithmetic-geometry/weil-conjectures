# CategoryTheory.ringedInternalHom_exact

## Reason

The generic ringed-site exactness interface identifies site-object, site-morphism
and coefficient universes. The small etale site in the assigned item has object
universe u+1 and morphism universe u, so this interface is unusable there.
Stacks Tag 08JC applies to the existing Hom-complex construction at independent
universes. Add that formulation while preserving the exact old theorem signature.
Its equal-universe case is definitionally the old derivedInternalHom construction:
the Hom complex, functorial K-injective resolution and localization lift agree,
with proof arguments irrelevant. No mathematical definition or statement changes.

The dependency module is unclaimed. No other group's module is edited.
No target needs renewed semantic review because no definition or target signature changes.
