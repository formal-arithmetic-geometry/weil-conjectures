# standardSingleFlatCounit_localization_completion

## Reason
The old arbitrary-P theorem is false for identity morphisms on Spec(k), M=O, P=0: eR in degree zero would identify zero with k. The proposed first repair also mistakenly supplied a global presentation on B. Use the actual local sheaf presentation on S, retaining K, e, t and their equation; construct P from that K. This is an intermediate-interface repair, not a proof or a target change.
