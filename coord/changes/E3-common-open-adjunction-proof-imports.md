# Common-stage open-adjunction proof imports

## Reason

The open-heart proof must precede WeilIndSheafCategory. Two unrelated imports formerly
made the coefficient constructions depend on that later consumer, forming a cycle.
Neither adapted module is currently claimed. No declaration, signature, visibility,
attribute or existing proof is changed.

## Old

In Sheaf.Paper.FieldStageOrdinaryRealization:

```lean
import Sheaf.Paper.SfCommonStageWeilCohomology
```

In Sheaf.Paper.SfRationalDirectImageCoefficientCompatibility:

```lean
public import Sheaf.Paper.WeilIndSheafCategory
```

## New

Remove the unused private import from FieldStageOrdinaryRealization.
Replace the public import in SfRationalDirectImageCoefficientCompatibility by:

```lean
public import Sheaf.Paper.DerivedPullbackTensorHom
```

The coefficient compatibility theorem only needs the underlying rational pullback,
stage systems and its prescribed comparison, all provided by this narrower module.
