# CategoryTheory element-site constructions: module extraction

## Reason

The three strictly smaller remaining obligations must import the concrete element-site
constructions without creating an import cycle through the existence theorem. Move those
constructions verbatim to a public construction module, and re-export them from the original
module. Names, universes, visibility, signatures and bodies of every existing declaration
are preserved. The original data structure and existence theorem stay in the item module.
The new module also defines the canonical Mathlib extension functor and proves its adjunction.


## New

The declarations listed above retain the same source text in
`Sheaf.CategoryTheory.RingedSheafSliceConstruction`. The original module now has:

```lean
public import Sheaf.CategoryTheory.RingedSheafSliceConstruction
public import Sheaf.CategoryTheory.RingedToposMorphism
```

The three new obligation modules are private proof imports. The construction module keeps
the original imports required for its public definitions, excluding SiteCoveringAxioms and
RingedToposMorphism: no construction uses either. RingedToposMorphism remains a direct public
import of the original item, where the data structure uses it. The unused site-axiom
predicate import is pruned. A canonical extension functor and the propositional interface
`elementModuleExtension_adjunction` are added; they instantiate existing proved Mathlib
adjoints and introduce no arbitrary choice from an unproved existence assertion.

The new presheaf-extension proof module uses private `@[no_expose]` definitions for
`rawSumFunctor`, `rawSumAdjunction` and `rawSumEvaluationIso`, replacing reducible
abbreviations of the same signatures and bodies. This keeps the constructed adjunction
out of reducible expansion. The proved `rawSumFunctor_map_lof` describes the functor on
each direct-sum inclusion. These names have no external users and change no public API.
