# AlgebraicGeometry.ProEtale.siteHomTensorParameterShift, siteHomSourceShift, siteHomOppositeSourceShift

## Reason

The native exactness theorem needs separately checkable zero/addition coherence and an ordinary
cone-boundary calculation. Both need the same explicit source-shift maps. Move those three maps
to the lower coherence module and publicly reexport that module from the original item, avoiding
an import cycle. Their types, names, irreducibility attributes, docstrings and bodies stay verbatim.
The new signed component is explicitly the prescribed scalar times the existing mate; it chooses
no data from an existence theorem.

## Old

In Sheaf.CategoryTheory.NativeDerivedHomSignedExact:

```lean
@[irreducible] def siteHomTensorParameterShift (K : D) (n : ℤ) :
    tensorLeft (K⟦n⟧) ≅ tensorLeft K ⋙ shiftFunctor D n :=
  NatIso.ofComponents (fun M ↦ (((curriedTensor D).flip.obj M).commShiftIso n).app K)
    (fun f ↦ (NatTrans.shift_app_comm ((curriedTensor D).flip.map f) n K).symm)

/-- The canonical source-Hom shift, as the right-adjoint mate of total-tensor shift.
This is the fixed-coefficient counterpart of the recorded ringed source shift, with
orientation H(K[n],-) → H(K,-)[-n]. Its opposite exact structure includes the correction
(-1)^(n(n+1)/2), prescribed below, rather than treating the raw shifts as coherent.
Source: Stacks 0A8X, 08JC (blueprint: lem-sf-site-hom-comparison-thick). -/
@[irreducible] def siteHomSourceShift (K : D) (n : ℤ) :
    ihom (K⟦n⟧) ≅ ihom K ⋙ shiftFunctor D (-n) :=
  (ihom.adjunction (K⟦n⟧)).rightAdjointUniq
    (((shiftEquiv D n).toAdjunction.comp (ihom.adjunction K)).ofNatIsoLeft
      ((tensorLeft K).commShiftIso n ≪≫ (siteHomTensorParameterShift K n).symm))
/-- The same canonical source shift with the opposite-category integer parameter.
The equality transport records -(-n)=n explicitly. Source: Stacks 08JC
(blueprint: lem-sf-site-hom-comparison-thick). -/
@[irreducible] def siteHomOppositeSourceShift (K : D) (n : ℤ) :
    ihom (K⟦-n⟧) ≅ ihom K ⋙ shiftFunctor D n :=
  siteHomSourceShift K (-n) ≪≫
    Functor.isoWhiskerLeft (ihom K) (eqToIso (congrArg (shiftFunctor D) (neg_neg n)))
```

## New

The exact declarations above occur in Sheaf.CategoryTheory.NativeHomSignedShiftLaws. The original
module publicly imports it, so its consumers see the same names with the same meanings. The new
explicit map is:

```lean
def siteHomSignedSourceComponent (M : D) (n : ℤ) (X : Dᵒᵖ) :
    (MonoidalClosed.internalHom.flip.obj M).obj (X⟦n⟧) ⟶
      ((MonoidalClosed.internalHom.flip.obj M).obj X)⟦n⟧ :=
  (n * (n + 1) / 2).negOnePow • (siteHomOppositeSourceShift X.unop n).hom.app M
```

No target statement or definition meaning changes. Existing consumers need no edits. Both direct
importers were compiled against the delivery: ExactDerivedHomComparisonShift (5.1 seconds) and
SiteHomComparisonThick (35.3 seconds). Their unchanged copies are excluded from the packet.
The downstream import scan is conservative: the full transitive list follows. Each effect is the
same because the old definitions and their public visibility are preserved verbatim.
