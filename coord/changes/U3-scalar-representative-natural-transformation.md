# AlgebraicGeometry.Etale.scalarExtensionRepresentative

## Reason

The repaired definition transposes the same ordinary adjunction unit through the
same derived scalar adjunction in a generic abelian category and bundles these
components into a natural transformation before specializing to sheaves. The
scalar representative is its component. It is still the canonical derived
extension counit specified by Stacks 06YY. The scalar-extension functor, scalar
adjunction, ordinary unit and quotient factor are unchanged; no existence
assumption is introduced. The repair removes redundant reflexive equality
transports from the returned packet, reducing repeated kernel comparisons.

## New

```lean
def scalarExtensionRepresentative
    {A B : Type (u + 1)} [CommRing A] [CommRing B]
    (φ : A →+* B) (T : Scheme.{u})
    (P : CochainComplex (Sheaf T.smallEtaleTopology (ModuleCat.{u + 1} A)) ℤ) :
    (scalarExtension φ T).obj (_root_.DerivedCategory.Q.obj P) ⟶
      _root_.DerivedCategory.Q.obj
        (((ProEtale.etaleSheafExtendScalars φ T).mapHomologicalComplex (.up ℤ)).obj P) :=
  (scalarExtensionRepresentativeTransformation φ T).app P
```

The public signature of scalarExtensionRepresentative and every existing public import remain unchanged.
