# Galois stalk coefficient universes

## Reason

The item quantifies over sheaves with values in Type (max u (v+1)). The existing
Galois stalk interfaces require Type (max (u+1) v), which cannot be specialized
to that universe when u exceeds v+1. Generalize the proved interfaces to
Type (max u v). This covers the existing case by v := max (u+1) v and the
item by v := v+1. There is no new mathematical hypothesis or changed Galois action.
All supporting modules were unclaimed when checked. No target signature changes.
The finite representable realization and coproduct construction now obtain
sheafification through the essentially u-small affine etale site, using Mathlib's
dense-subsite equivalence. This avoids requiring a large-site sheafification
instance unavailable at the smaller coefficient universe. It constructs the
same sheafification, with its universal property determining it uniquely.
