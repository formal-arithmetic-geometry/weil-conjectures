# KFlat proof-local commands

## Reason

The static interface checker conservatively flags added variable, open, and local
notation commands needed by private proof helpers. Existing public signatures,
definitions, imports, and instance attributes are unchanged. The helpers are all
private, their simp attributes are local, and they are used only in theorem proofs.
No mathematical statement or definition is changed.

## Old

The file has no PresheafOfModules proof-helper namespace, no tensor–Hom helper
variables, no local 𝓡/𝓢/𝓦 notation, and no `open scoped ZeroObject` command.

## New

Added the proof-local namespace context:

```lean
open scoped ZeroObject
namespace PresheafOfModules
open Opposite
variable {C : Type u} [Category.{v} C] {R : Cᵒᵖ ⥤ CommRingCat.{max u v}}
  {M P N : PresheafOfModules.{max u v} (R ⋙ forget₂ _ _)}
```

This namespace closes before the existing SheafOfModules namespace. Added local
notation 𝓡 for the forgotten ring sheaf, 𝓢 for its sheafification functor, and 𝓦
for the inverse image of J.W; see the delivered module for their exact expansions.
All new lemmas and constructions are private. No exported signature changes.
