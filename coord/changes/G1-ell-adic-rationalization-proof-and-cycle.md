# Ell-adic rationalization proof and coefficient import cycle

## Reason

Close both existing holes of the source module using the canonical exact-derived
comparison and already proved archived helpers. The source imports only new private
proof dependencies. The helper archive and the continuous integral model/denominator
modules currently reach the source through this path:

`IntegralConstructibleSheafHom -> CondensedLocallyClosedExtensionTower ->
CondensedLocallyClosedOneStep -> CondensedOpenClosedRecollement ->
BaseChangeTheorems.MorphismDefs -> Derived.BoundedConstructible ->
CompletedCondensedCoefficients -> EllAdicRationalization`.

The final edge is an unused private import in the unclaimed Sheaf module. Removing
only that line breaks the cycle, and the adapted module compiles unchanged otherwise.
No declaration, definition, signature, public import or public attribute is modified.

```lean
      (Rationalization.W (Submonoid.powers (ℓ : ℤ))
        (BoundedConstructible (condensedRingObj (Profinite.padicIntegersRingObj ℓ E.1) X)))
```


## New

Both displayed signatures stay verbatim and both bodies are complete proofs.
The preservation lemma specializes exact scalar extension and the generic preservation
of bounded constructibility. The localization proof equips the actual derived
extension with its shift and triangulated structure via the canonical termwise
comparison, then supplies existing integral models, denominator clearing and equality
detection to the proved archived full-subcategory localization helper.

Added local reducibility commands keep the large pullback and derived constructions
abstract while their APIs are used:

```lean
attribute [local irreducible] upperStarFromPoint Mod.extendScalars
  CategoryTheory.Functor.leftDerivedFunctor CategoryTheory.Functor.mapDerivedCategory
```

These expire at namespace end. No importer-visible attribute changes. The only edit
to `Sheaf.Paper.CompletedCondensedCoefficients` removes the displayed private import.
All its declarations and its public imports are byte-identical. It contains no textual
reference to any declaration of the source module. Its own explicit coefficient,
scalar-extension, and ring-object imports suffice for its unchanged proofs.
No target definition or target statement changes; no target review is reopened.
