# constructiblePullbackResidueUnits

## Reason

The former abbreviation extracts inverse structures from the entire unproved
constructible-truncation existence package. Its expansion also brings that large
witness into elaboration of the pullback interfaces. Replace it by the elementary
characteristic calculation and a named proved lemma. `Invertible a` is a subsingleton,
so this changes neither the inverse nor any target meaning. The empty scheme is
vacuous, and the helper works for arbitrary schemes over the base, without finite type.
The original definition keeps all its binders. The new helper has a complete
proof without any project theorem assumption: only fields, characteristic,
global-section evaluation and ring-map preservation of units are used.

The new definition intentionally keeps the cached inverse folded and has a
file-local irreducibility
attribute. Automatic size/injectivity generation is disabled in this file only; no
mathematical declaration is removed. Existing public imports and theorem signatures
are retained. The only added import is a private proof import of CharAndCard. The scoped
warn.classDefReducibility option documents intentional semireducibility of these
cached class data; Mathlib uses the same convention for selected class-valued
constructions. It suppresses no proof or axiom check.

## Old

```lean
abbrev constructiblePullbackResidueUnits (Y : Scheme.{u})
    [Y.Over (Spec (.of D.k))]
    [LocallyOfFiniteType (Y ↘ Spec (.of D.k))] [QuasiCompact (Y ↘ Spec (.of D.k))] :
    ∀ y : Y, Invertible (l : Y.residueField y) :=
  (constructibleTruncations_exists D l hl Y
    (AlgebraicClosure (Padic l))).choose_spec.choose_spec.choose
```

## New

```lean
set_option warn.classDefReducibility false in
def constructiblePullbackResidueUnits (Y : Scheme.{u})
    [Y.Over (Spec (.of D.k))]
    [LocallyOfFiniteType (Y ↘ Spec (.of D.k))] [QuasiCompact (Y ↘ Spec (.of D.k))] :
    ∀ y : Y, Invertible (l : Y.residueField y) :=
  fun y ↦ (constructiblePullbackResidue_isUnit D l hl Y y).invertible
```

`constructiblePullbackResidue_isUnit` obtains characteristic p from the cardinality
of the finite base field, proves l is nonzero there, and maps the resulting unit
to each residue field. It has no sorry and introduces no hypothesis downstream.
