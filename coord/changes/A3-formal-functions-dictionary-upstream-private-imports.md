# AlgebraicGeometry.formalFunctions_affine_restriction_dictionary

## Reason

The upstream sync moved restriction helpers into source modules and retired the Sheaf
modules as public re-export wrappers. `import all` on a wrapper does not expose the
upstream module's private helpers. The sync consequently commented out the dictionary,
and the assigned item failed with `Unknown identifier formalFunctions_affine_restriction_dictionary`.
Restore the existing dictionary theorem and its proof, import its private helpers from
their actual upstream modules, and explicitly use the quasi-coherence restriction lemma.
No definition or target statement changes. The dictionary module is unclaimed at this
repair; H2 has an upstream return entry but holds no claim on this module.

import `Mathlib.Algebra.Category.ModuleCat.Sheaf.Limits`: the dictionary constructs only

import removed, and the pushforward item imports its required evaluation-limit
