# WeilConjectures.ConstructibleExceptionalCoefficients.scalarShiftLocalization

## Reason

Zheng, Constructions 6.1 and 6.2, transports coefficient operations and their exact
comparison squares through localization. The old predicate instead required a literal
heterogeneous component formula for every integer shift, deleting both endpoint
rationalization shift comparisons. The existing chosen rational triangulation only
specifies the tensor shift and identity localization component at shift one. For other
integers, coherent shifts may be presented by isomorphic functors with different
objects, so deleting the canonical endpoint comparisons is unjustified.

The repaired predicate asserts that the identity-normalized scalar localization
comparison is a natural isomorphism commuting with every integer shift. It retains
both fixed integralRationalizationShift structures. Thus it expresses the actual
exact localization square, without imposing a new strict presentation of the chosen
rational shifts. The main theorem retains its original parameters and literal q-component
formula; explicit universe arguments and equality-binder types aid elaboration. This is a definition correction, not a proof of the old strict predicate.
No target statement or definition occurring in a Challenge target type is edited.

```lean
@[irreducible]
def scalarShiftLocalization
    (E L : FieldStage.{max u v} l) (i : E.carrier →ₐ[Padic l] L.carrier)
    (T : Scheme.{max u v})
    (S : Scalar.{u, v} l Ω (s := .integral E) (t := .integral L)
      (PurCompactSupport.completedChange l E.carrier L.carrier i) T)
    (cs : (rationalScalar.{u, v} l Ω E L i T).CommShift ℤ) : Prop :=
  letI := cs
  letI := S.commShift
  letI := integralRationalizationShift.{u, v} l Ω E T
  letI := integralRationalizationShift.{u, v} l Ω L T
  ∃ c : rationalization.{u, v} l Ω E T ⋙ rationalScalar.{u, v} l Ω E L i T ≅
      S.functor ⋙ rationalization.{u, v} l Ω L T,
    (∀ K, HEq (c.hom.app K)
      (𝟙 ((rationalScalar.{u, v} l Ω E L i T).obj
        ((rationalization.{u, v} l Ω E T).obj K)))) ∧
    c.hom.CommShift ℤ
```
