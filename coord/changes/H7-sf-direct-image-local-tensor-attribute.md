# AlgebraicGeometry.Etale.directImageCTFNonproper: local tensor attribute

## Reason

Stage-3 preflight requires a change record for the added scoped attribute command.
The private proved equivalence between the two Tor-amplitude predicates unfolds
`derivedTensor` explicitly. Making it locally irreducible prevents repeated expansion
through the concrete coefficient-ring hierarchy at the application sites. The
attribute ends with the namespace scope and does not change imported behavior,
existing public signatures, public definitions, or target meaning. No consumer
source adaptation is proposed.

## Old

The existing namespace opening was:

```lean
namespace AlgebraicGeometry.Etale
```

No attribute command or private conversion helper followed it. The existing
`directImageCTFNonproper` signature is retained verbatim in the delivered module.

## New

The namespace opening now includes:

```lean
namespace AlgebraicGeometry.Etale

attribute [local irreducible] derivedTensor
```

The private proved helper `hasTorAmplitudeIn_iff_torAmplitudeIn` and the completed
proof of `directImageCTFNonproper` follow this command. No existing definition or
statement has changed. The helper unfolds the tensor explicitly only while
converting the cohomology-vanishing and t-structure predicates.
