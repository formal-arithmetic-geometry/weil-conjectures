# AlgebraicGeometry.ProEtale.upperStarCompIso

## Reason

The fixed-field transposition proof exceeded the kernel heartbeat/time limit when specializing the commutative-square ring comparison. The old natural-isomorphism composite exposes large inverse-image constructions while comparing its components at coefficient sheaves. Name its explicitly typed forward and inverse component maps and rebuild the natural isomorphism from them. `upperStarCompIso_eq_composite` proves equality to the original construction by `rfl`; all existing signatures and visibility stay unchanged. This is a representation repair, with no new mathematical hypothesis or choice. The source module was unclaimed.

Three unclaimed consumers use the old expression syntactically. The original quotient proof failed at line 47 because the composite pattern disappeared; the original WeilSheaf proof failed at lines 53 and 118 for the same reason. The original CoherenceLegacy consumer exceeded 60 seconds while comparing the rebuilt comparison with a factorization composite. Their only edits rewrite with the equality API before the old proof. All adapted consumers compile.

Any Challenge target whose definitions use this comparison requires the prescribed statement-meaning review. The equality theorem identifies the exact old comparison, so its mathematical meaning is unchanged. No target statement is edited.

## New

```lean
/-- The component of the square comparison, with its source and target specified. -/
noncomputable def upperStarCompIsoHom {Y Z₁ Z₂ T : Scheme.{u}} {a : Y ⟶ Z₁} {b : Z₁ ⟶ T}
    {c : Y ⟶ Z₂} {d : Z₂ ⟶ T} (h : a ≫ b = c ≫ d)
    (M : Sheaf (ProEt.topology T) A) :
    (a)^*[A].obj ((b)^*[A].obj M) ⟶ (c)^*[A].obj ((d)^*[A].obj M) :=
  ((upperStarComp A a b).symm ≪≫ upperStarCongr A h ≪≫ upperStarComp A c d).hom.app M

/-- The inverse component of the square comparison. -/
noncomputable def upperStarCompIsoInv {Y Z₁ Z₂ T : Scheme.{u}} {a : Y ⟶ Z₁} {b : Z₁ ⟶ T}
    {c : Y ⟶ Z₂} {d : Z₂ ⟶ T} (h : a ≫ b = c ≫ d)
    (M : Sheaf (ProEt.topology T) A) :
    (c)^*[A].obj ((d)^*[A].obj M) ⟶ (a)^*[A].obj ((b)^*[A].obj M) :=
  ((upperStarComp A a b).symm ≪≫ upperStarCongr A h ≪≫ upperStarComp A c d).inv.app M

/-- The pullbacks along the two sides of a commutative square `a ≫ b = c ≫ d` agree:
`a^* ∘ b^* ≅ (a ≫ b)^* = (c ≫ d)^* ≅ c^* ∘ d^*`. -/
noncomputable def upperStarCompIso {Y Z₁ Z₂ T : Scheme.{u}} {a : Y ⟶ Z₁} {b : Z₁ ⟶ T}
    {c : Y ⟶ Z₂} {d : Z₂ ⟶ T} (h : a ≫ b = c ≫ d) :
    (b)^*[A] ⋙ (a)^*[A] ≅ (d)^*[A] ⋙ (c)^*[A] :=
  let e := (upperStarComp A a b).symm ≪≫ upperStarCongr A h ≪≫ upperStarComp A c d
  NatIso.ofComponents (fun M ↦
    { hom := upperStarCompIsoHom A h M
      inv := upperStarCompIsoInv A h M
      hom_inv_id := e.hom_inv_id_app M
      inv_hom_id := e.inv_hom_id_app M })
    (fun k ↦ e.hom.naturality k)

/-- The component presentation is the original composition of inverse-image comparisons. -/
theorem upperStarCompIso_eq_composite {Y Z₁ Z₂ T : Scheme.{u}}
    {a : Y ⟶ Z₁} {b : Z₁ ⟶ T} {c : Y ⟶ Z₂} {d : Z₂ ⟶ T}
    (h : a ≫ b = c ≫ d) :
    upperStarCompIso A h =
      (upperStarComp A a b).symm ≪≫ upperStarCongr A h ≪≫ upperStarComp A c d := by
  rfl
```
