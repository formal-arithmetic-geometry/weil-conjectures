# CategoryTheory.Precoverage finite indexed closure axioms

## Reason
The unrestricted `Precoverage.IsStableUnderBaseChange` and
`Precoverage.IsStableUnderComposition` conclusions are false for filtered unions of
finite covering families (the chaotic-category counterexample in the returned report).
Stacks 09YL uses finite indexed covering families, so the interface is corrected to
finite-index closure classes.
