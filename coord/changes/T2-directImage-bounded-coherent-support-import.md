# AlgebraicGeometry.Scheme.directImage_isBounded_coherent imports

## Reason

Use the support compatibility module to avoid importing duplicate support declarations
against the published build. In the current source this compatibility module publicly
imports the upstream module below, and adds no declarations. Its extra public imports
are already public imports of that upstream module. The theorem's elaborated type,
all definitions, and the exported source environment therefore retain their meaning.

Second reading also removes the redundant public `HomologySequence` import, which
`Sheaf.AlgebraicGeometry.DerivedCategory` already publicly re-exports through its
upstream module. This changes no public visibility; the full proof compiles without it.
