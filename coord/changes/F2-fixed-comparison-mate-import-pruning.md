# FixedComparisonDirectImageMate public imports

## Reason

The original ProEtaleSiteComparison wrapper is unused by the definitions and proofs.
Its only needed coefficient-category support is Mathlib.Algebra.Category.ModuleCat.AB,
which is now imported directly. This prunes the unused wrapper and preserves all four
existing declaration signatures and both definition bodies. No target statement or
mathematical definition changes. The original Etale coherence import is retained because
it declares Etale.rightDerivedLowerStarPlus, used in the existing public signatures.
The proof-only MapDerivedCategoryMate import supplies the inverse-isomorphism identity.
