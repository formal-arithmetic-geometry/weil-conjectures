# AlgebraicGeometry.Scheme.pbcDescentFunctors

## Reason

The proof introduces generic private stage-system helpers. The interface checker
conservatively flags their section variables, local options and section commands
as changes to commands outside declaration bodies. This record documents that
flag. All original public signatures, definitions and visibility remain identical;
only the proof of pbcDescentFunctors changes. No target statement changes and no
consumer needs adaptation.

## Old

The public theorem signature, verbatim:

```lean
theorem pbcDescentFunctors
    (F : StageSystem.CoherentExactMorphism
      (pbcScalarSystem l Ω T dT.out iT.out) (pbcScalarSystem l Ω S dS.out iS.out)) :
    StageSystem.Morphism.DescentSpec F.base
```

Its proof was `:= sorry`. There were no private generic descent helpers between
Morphism.DescentSpec and the AlgebraicGeometry.Scheme namespace.

## New

The public theorem signature, verbatim:

```lean
theorem pbcDescentFunctors
    (F : StageSystem.CoherentExactMorphism
      (pbcScalarSystem l Ω T dT.out iT.out) (pbcScalarSystem l Ω S dS.out iS.out)) :
    StageSystem.Morphism.DescentSpec F.base
```

The proof now applies the proved private canonicalDescent theorem. New private
helpers are additive_of_stage, shiftHom, shiftIso, shiftIso_hom_app,
descendedCommShift, inclusionComp_commShift, triangulated_of_stage and
canonicalDescent, in CategoryTheory.StageSystem or its Morphism namespace.
The new StageShift and ExactShift sections scope their variables. The local
respectTransparency options apply only to the following private declaration.
No helper is an exported instance. No original declaration gains a binder.
The unused proof-only import Sheaf.Paper.IntrinsicQbarCategory is removed;
public imports are identical.
