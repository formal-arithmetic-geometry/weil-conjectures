# AlgebraicGeometry.EtaleLogStructure.imageIdealSections

## Reason

The three smaller geometric theorem modules must refer to the existing image,
chart and inclusion predicates without importing the theorem that combines
them. Extracting the existing data into a common module removes that cycle.

## New

Exactly the same seven declaration signatures, bodies and docstrings are
in `Sheaf.AlgebraicGeometry.LogIdealAlgebraizationData`, in the same order.
The item publicly imports this data module. Its eight old direct public
imports are now re-exported through that module, which retains those imports
verbatim; the full public dependency closure is preserved. No definition, theorem statement, instance, exported attribute,
visibility or mathematical meaning changes. Within the item proof only,
`Scheme.IdealSheafData.toModules` and `toModulesι` are marked locally
irreducible and backward transparency checks are enabled, so equalities of
ideal modules use their API instead of unfolding their kernel constructions.
The local reducibility attributes are not exported to importers.
