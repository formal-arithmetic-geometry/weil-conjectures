# CategoryTheory.ModuleRestrictionKernel: scoped proof commands

## Reason

Preflight conservatively classifies added `omit` and scoped `set_option` commands as an
interface change. This record documents those proof-context additions. The static declaration
comparison confirms zero changed existing signatures, zero public additions and identical
public imports. All nine added helpers are private and proved. Existing definition and
instance bodies remain unchanged. No mathematical definition or target statement changes.

## Old

The existing abelian-only public proofs had no `omit` prefix. The location before the main
theorem contained no private comparison-computation or acyclic-complex helper.
The file-level context was and remains:

```lean
set_option autoImplicit false
universe u w uB vB uD vD
open CategoryTheory CategoryTheory.Limits Opposite
```

## New

Three abelian-only declarations receive this exact prefix:

```lean
omit [HasWeakSheafify J RingCat.{u}] in
```

These are `s₀AdditiveProof`, `s₀LeftExact` and the new private
`abelianRestrictionSurjective`. The prefix explicitly drops an irrelevant section instance;
the pre-existing two public theorem types are identical to their original types.

The new private `comparisonCompute` has these exact scoped options:

```lean
set_option backward.isDefEq.respectTransparency false in
set_option backward.isDefEq.respectTransparency.types false in
```

The new private `mapAcyclicQuasiIso` has this exact prefix:

```lean
omit [HasWeakSheafify J RingCat.{u}]
  [HasDerivedCategory.{w} (Sheaf J AddCommGrpCat.{u})]
  [HasDerivedCategory.{w} AddCommGrpCat.{u}] in
```

Each command applies to one declaration only. Importers inherit no option, notation or
instance registration from these prefixes. No existing public declaration changes meaning,
so no target statement review is reopened. Proof-only imports and the updated DAG route are
listed in the report.
