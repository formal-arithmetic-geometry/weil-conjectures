# AlgebraicGeometry.relative_spec_morphism_chart

## Reason

The original arbitrary equivalence was constrained only on objects. Counit naturality supplies E.functor.map, whereas the chart formula uses the canonical section map of the underlying scheme morphism. These maps agree only with hmap, which the parent already constructs.

The missing assumption is substantive: conjugating all morphisms of the affine-over-S category by a chosen family of object automorphisms gives an equivalence identical on objects but with a different action on morphisms. Over Spec Q, choose a translation automorphism of an affine-line object and a scaling endomorphism that does not commute with it. Composing the canonical anti-equivalence with this conjugation preserves hobj; its inverse sends the algebra scaling map to the conjugated scheme map. With the canonical counit charts it fails the original chart equation. This explains the defect; no Lean counterexample theorem is claimed.

The corrected hypothesis is exactly the morphism formula in the existing parent statement and in Stacks 01SA. No target, definition, or parent signature changes. This is a corrected-statement proof, not a proof of the original overgeneralized statement.

The unused public import of AffineStructureAlgebraFullyFaithful is replaced by its three statement-level public imports. The chart proof does not use that theorem. The parent already explicitly imports it for its separate full-faithfulness step; this delivery does not prune that step or its unit.
