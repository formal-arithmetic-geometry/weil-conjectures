# AlgebraicGeometry.Etale.derivedTensorSymmetry

## Reason

A direct specialization of the upstream braided-pullback theorem repeatedly exceeded the
60-second single-file limit or the kernel heartbeat budget when identifying the packaged
symmetry with the derived braiding. Package the already existing braiding in a generic
abelian category before specializing to etale sheaves. The proved generic equation
`DerivedCategory.canonicalTensorSymmetry_eq` identifies the new wrapper with the original
`DerivedMonoidal.canonicalBraidingNatIso` construction. This changes neither the signed swap
nor its naturality, the tensor bifunctor, any target meaning, or any existing signature.
The module is unclaimed. The added public import supplies the existing named derived braiding;
it adds no instance. No consumer requires adaptation.

## Old

```lean
noncomputable def derivedTensorSymmetry
    (A : Type u') [Category.{u + 1} A] [Abelian A]
    [IsGrothendieckAbelian.{u + 1} A] [MonoidalCategory A] [MonoidalPreadditive A]
    [SymmetricCategory A] [MonoidalClosed A] [Abelian.HasFunctorialFlatResolution A]
    (T : Scheme.{u}) : derivedTensor A T ≅ (derivedTensor A T).flip :=
  DerivedMonoidal.canonicalBraidingNatIso DerivedCategory.Qh
    (HomotopyCategory.quasiIso (Sheaf T.smallEtaleTopology A) (ComplexShape.up ℤ))
```

The canonical localization package on the current source base was:

```lean
noncomputable def canonicalBraidingNatIso
    {C : Type u'} {D : Type u} [Category.{v₁} C] [Category.{v₂} D]
    [MonoidalCategory C] [BraidedCategory C] (F : C ⥤ D) (W : MorphismProperty C)
    [F.IsLocalization W] [W.ContainsIdentities] [F.HasDerivedMonoidalCategory W] :
    bifunctor F W ≅ (bifunctor F W).flip :=
  NatIso.ofComponents (fun K ↦
    NatIso.ofComponents (fun L ↦ braiding' F W K L)
      (fun f ↦ braiding_naturality_right F W K f))
    (fun f ↦ NatTrans.ext (funext (fun L ↦ braiding_naturality_left F W f L)))
```

## New

```lean
noncomputable def derivedTensorSymmetry
    (A : Type u') [Category.{u + 1} A] [Abelian A]
    [IsGrothendieckAbelian.{u + 1} A] [MonoidalCategory A] [MonoidalPreadditive A]
    [SymmetricCategory A] [MonoidalClosed A] [Abelian.HasFunctorialFlatResolution A]
    (T : Scheme.{u}) : derivedTensor A T ≅ (derivedTensor A T).flip :=
  DerivedCategory.canonicalTensorSymmetry (Sheaf T.smallEtaleTopology A)
```

The generic `DerivedCategory.canonicalTensorSymmetry` uses
`BraidedCategory.curriedBraidingNatIso` with the existing derived braided-category instance.
It selects the named instance `DerivedCategory.braidedCategory' C`, with the prior name
`DerivedCategory.braidedCategory C` as an elaboration fallback for the published build.
Selecting this wrapper directly avoids the expensive concrete instance comparison caused
by inferring the instance through `DerivedMonoidal`. Its equality with the old localization
package is proved by `rfl` before specializing to sheaves. The generic localization package retains the exact
hom, inv, and inverse laws of the existing `DerivedMonoidal.braiding'`; these fields are
spelled out to support both the current source names and the published build's prior names.
This is an implementation change to the same canonical object.

The same canonical localization package, with its isomorphism fields explicit:

```lean
noncomputable def canonicalBraidingNatIso
    {C : Type u'} {D : Type u} [Category.{v₁} C] [Category.{v₂} D]
    [MonoidalCategory C] [BraidedCategory C] (F : C ⥤ D) (W : MorphismProperty C)
    [F.IsLocalization W] [W.ContainsIdentities] [F.HasDerivedMonoidalCategory W] :
    bifunctor F W ≅ (bifunctor F W).flip :=
  NatIso.ofComponents (fun K ↦
    NatIso.ofComponents (fun L ↦
      { hom := ((braidingNatTrans F W).app L).app K
        inv := ((braidingInvNatTrans F W).app K).app L
        hom_inv_id :=
          congr_app (congr_app (braidingNatTrans_comp_braidingInvNatTrans F W) K) L
        inv_hom_id :=
          congr_app (congr_app (braidingInvNatTrans_comp_braidingNatTrans F W) L) K })
      (fun f ↦ braiding_naturality_right F W K f))
    (fun f ↦ NatTrans.ext (funext (fun L ↦ braiding_naturality_left F W f L)))
```
