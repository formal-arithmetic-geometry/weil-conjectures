# Rep.continuousCochains_shortExact import interface

## Reason

The proof needs only the abelian-structure and forgetful exactness theorem
`Rep.discreteRep_abelian_structure`, which is already proved at arbitrary carrier universe.
The removed umbrella module additionally contains the still-unproved enough-injectives
assertion at an independent small carrier universe. Its known size defect is recorded in
`coord/changes/G3-discrete-continuous-injectives-universes.md`.
Use the actual discrete-action category and the topology class needed by the statement as
public imports, and import the abelian-structure theorem only for the proof.
No declaration signature, definition, visibility or target changes.

```lean
public import Sheaf.CategoryTheory.DiscreteModulesAbelian
```

## New

```lean
public import WeilConjectures.RepresentationTheory.DiscreteContinuousRep
public import Mathlib.Topology.Connected.TotallyDisconnected
import Sheaf.RepresentationTheory.DiscreteRep
```

All other existing public imports remain unchanged.
