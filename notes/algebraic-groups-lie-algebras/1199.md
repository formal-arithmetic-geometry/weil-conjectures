# Issue 1199: Cartier's theorem (`sk-i-cartier`)

## `AlgebraicGeometry.isReduced_of_grpObj` is false as stated

The statement is

```lean
variable {K : Type u} [Field K] [CharZero K] {G : Scheme} (f : G ⟶ Spec (.of K))
  [LocallyOfFiniteType f] [GrpObj (Over.mk f)]

theorem isReduced_of_grpObj : IsReduced G
```

The type `IsReduced G` does not mention `f`, so Lean drops `f`, `K` and their instance arguments,
and the theorem elaborates to

```lean
isReduced_of_grpObj : ∀ {G : Scheme}, IsReduced G
```

It claims that every scheme is reduced, which is false, e.g. for `Spec (K[X] ⧸ (X ^ 2))`. So it
stays `sorry`.

**Proposed change:** put `include f in` before the theorem. The correct statement is proved
under the name `AlgebraicGeometry.isReduced_of_grpObj_of_charZero`. Once the statement is fixed,
the proof is `isReduced_of_grpObj_of_charZero f`, and the helper can be removed.

## Remaining gap

`smooth_of_grpObj_of_charZero` and `isReduced_of_grpObj_of_charZero` are proved from
`isReduced_of_grpObj_of_isAlgClosed`. That is the non-affine case over an algebraically closed
field, and it is still `sorry` (it was `sorry` on slopmaster too). The affine case
`isReduced_of_grpObj_of_isAffine` is sorry-free, via Cartier for Hopf algebras
(`HopfAlgebra.isReduced_of_charZero`). The non-affine case needs invariant vector fields on a
non-affine group scheme and is split off as its own issue.
