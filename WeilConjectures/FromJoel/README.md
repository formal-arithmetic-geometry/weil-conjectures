# FromJoel

The files in this directory were written by **Joël Riou**. We took them from the branch
[`jriou_localization`](https://github.com/joelriou/mathlib4/tree/jriou_localization) of his Mathlib fork
(<https://github.com/joelriou/mathlib4/tree/jriou_localization>),
which had not yet been merged into Mathlib.

They cover:
- localization of categories and derivability structures;
- derived categories, homotopy categories and embeddings of complexes;
- derived functors;
- the related homological algebra.

The rest of the project builds the six-functor formalism and étale cohomology on top of this material.

We kept each file's original header (`Copyright (c) … Joël Riou`, `Authors: Joël Riou`). Like the
rest of this repository, the files are released under the Apache 2.0 license. Our only changes
adapt them to the Mathlib version this project uses: module paths under
`WeilConjectures.FromJoel`, imports, and fixes for upstream renames.

We thank Joël Riou for making this work available.
